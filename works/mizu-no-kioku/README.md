# 水の記憶 — Memory of Water

**🌐 https://mizu-no-kioku.vercel.app**

2026-07-25 / クリエイティブコード作品（単一 `index.html`・WebGL2・依存ゼロ）

月夜の石鉢。落ちた一滴は波紋になり、鉢の縁で返り、他の波紋と干渉して消えていく。
消えたあとも、水が動いた場所は床に鉱物のように**堆積**する。それが「水の記憶」。
やがてそれも忘れられていく。

## 中身

### 1. 水面 — 物理で解く（1024² の RGBA32F を ping-pong 積分）

状態は 1 テクセルあたり `(h, v, mem, env)`。

- **可変水深の浅水波** `h_tt = ∇·(c²∇h)` — 鉢は椀状で、`c² ∝ 水深`。
  縁で波が遅くなり屈折して立ち上がる（浅水変形＝shoaling）。
- **毛細管分散** `−σ∇⁴h`（13点ステンシル）→ 分散関係 `ω² = c²k² + σk⁴`。
  細かい波ほど速く走る＝実際のさざ波の挙動。
- **粘性減衰** `+ν∇²v` — 高波数ほど速く減衰。細波が先に凪ぎ、うねりが残る。
- **k=0 復元項** `−K·h` — 波動方程式は一様な水位変化に力を及ぼさないので、
  外力のわずかな直流成分で水位が際限なくドリフトする。それを止める。
- 縁は滑らかなピン留め境界（波は反射して戻り、干渉する）。

**安定条件（重要）**：最悪モード (π,π) で `∇²→−8`, `∇⁴→+64` なので
`8·C2 + 64·S4 < 4`。これを超えると格子スケールの市松振動が出て、
画面には「細い蛇行する暗線」として現れる。現在値は約 2.3。

### 2. 光 — 本物の屈折で描く

**コースティクス**は Yuksel & Keyser (2009) *Fast Real-time Caustics from Height Fields*
の考え方を、**等エネルギー光子の密度**として実装したもの。

- 1408² 個の光子を水面格子から射出し、`refract()` で屈折させて椀の底との交点を求める
  （曲面床なので 1 回反復）。着地点に加算スプラットし、その**密度**がコースティクスになる。
- 面積比 `1/|det J|` を陽に計算する教科書どおりの三角形方式も試したが、
  折り返し（fold）でセルが針状に潰れるとラスタライザが部分被覆を表現できず、
  エネルギーが破綻して**数珠状の暗線**が出る。密度方式なら折り返しは素直な重ね合わせになる。
- 光子はセル内でジッタする。規則格子のままだと出力グリッドとのモアレが出る。
- 総光量は水面の荒れ方によらず一定 → **マップ平均（ミップ縮約）で正規化**して露出を安定させる。

**水面の見え**は Schlick フレネルで反射と屈折を混ぜる。
屈折は R/G/B で屈折率をずらして分散を出し、Beer–Lambert で藍に沈める。
鏡面は月光の道（glitter path）。環境は手続きで、鋭い月＋暈＋対岸の淡い帯。

### 3. 記憶 — 二つの時定数

- `mem`（堆積）：`mem ← mem·decay + |h|·rate`。半減期およそ 50 秒。
  水がよく動いた場所ほど厚く積もる。厚みで色が銀↔金に振れる。
- `env`（痕跡）：`env ← max(env·decay, |h|)` の包絡線。干渉の腹／節が線として刻まれる。

どちらも床のアルベドに乗るので、**コースティクスに照らされて初めて見える**。

### 4. 後処理

HDR(RGBA16F) → 輝度抽出 → 2段ブルーム（1/4・1/16）→ ACES → 周辺色収差・ヴィネット・粒子・ディザ。

## パス構成（1 フレーム）

```
1. 波           1024²  RGBA32F  ping-pong ×2サブステップ（フレーム時間に追随）
2. 法線＋記憶   1024²  RGBA16F  Sobel勾配を線形補間できる形に落とす
3. コースティクス 768²  RGBA16F  1408² 光子を加算スプラット → ぼかし → ミップ縮約
4. 本描画       画面   RGBA16F
5. ブルーム     1/4・1/16
6. 合成         画面
```

低速な環境では fps を見て光子数を 2 段まで自動的に落とす。
