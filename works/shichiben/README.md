# 七弁 — Shichiben（2026-09-05・ccf5 art）

球では五弁が十二だけ（十二の疵）、平面では六弁（正本）、双曲平面では七弁の花が無限に咲く。生命の花の三部作を結ぶ。3〜4月の hyperbolic-flower-2d / poincare-bloom-2d の作り直し。

## 数学
- ポアンカレ円板の {3,q} 三角形タイリング（q=7,8,9,12）。頂点を中心に、辺の長さ L を半径とする双曲円＝生命の花の作図そのもの。cosh(L/2) = cos(π/3)/sin(π/q)、cosh R = cot(π/3)cot(π/q)、三角形の面積 = π(1−6/q)（角欠損）。
- 折り畳み：(2,3,q) 三角群の鏡映＝実軸・角 π/q の直線・O と V1 の垂直二等分測地線（中心 (1+ρ_m²)/2ρ_m）、さらに遠い辺 V1V2 の測地線（O を鏡映した第二環の頂点 V3 に近いとき）。最大40回で基本三角形（V0, 辺の中点, 三角形の中心）へ落ちる。
- 双曲距離は cosh d = 1 + 2|z−w|²/((1−|z|²)(1−|w|²))。線までの距離 |d−L| は cosh の差を sinh L で割って一次近似。線幅は共形因子 (1−|z|²)/2 で割り、画面上で一定。
- 中心の候補は O・扇の隣 k=−4..5・第二環（辺 V1V2 と V−1V1 の向こう）の13点。q が大きいほど遠い隣の弧が基本領域をかすめる（6点では q=12 で弧が途切れた）。
- ドラッグ＝メビウス変換 z→(z−c)/(1−c̄z) の合成（c' = (c+d)/(1+c̄d)）。双曲平面を滑ると、無限の花が縁から湧く。
