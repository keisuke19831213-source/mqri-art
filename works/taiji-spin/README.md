# TAIJI SPIN — 太極回転

太極図をどれだけの速さで回すかだけを、指先で決められるインタラクティブアート。

止まっているときはただの陰陽図でしかない。けれど回転速度が画面の更新間隔と
噛み合いはじめると、そこには誰も描いていない模様が現れる。
4枚の花、6回対称の車輪、ゆっくり逆回りに転がる二重の像 — すべて、
回転する黒と白のあいだにしか存在しない。

## ストロボ錯視

ディスプレイは1秒間に決まった回数しか絵を描き換えられない。
そのため「1フレームあたり何度回るか」(°/frame)が 360/N に近づくと、
図はN箇所で静止して見え、N回対称の模様として知覚される。

| °/frame | 見えるもの |
|---|---|
| 30 | 12回対称の細かなちらつき |
| 45 | 8枚の花 |
| 60 | 6回対称の車輪 |
| 90 | 4つの眼が渦を巻く |
| 120 | 3回対称 |
| 179 | ほぼ静止した像がゆっくり逆回転する |
| 180 | 陰と陽が融合した二重露光像 |

太極図は 180° 回すと白黒を入れ替えた自分自身と重なる。
この性質のため ±180°/frame では「図」と「そのネガ」が毎フレーム交互に現れ、
そのままでは目に痛い点滅にしかならない。176°/frame を超えた分だけ半回転先の像を
混ぜ、角度を 180° で正規化することで、静止した二重露光像に収束させている。

## 操作

- **ドラッグ**:掴んで回す。離すと勢いのまま回り続ける
- **速度** −180〜180 °/frame(スライダー、または数値を直接入力)
- **残像**:過去のフレームを溶かし込む長時間露光
- **大きさ**:画面短辺に対する直径
- **自動加速**:100秒かけて最高速へ
- **反転**:白地に黒
- **鑑賞モード**(`A`):下記
- `H` パネル表示切替 / `Space` 停止

## 鑑賞モード

パラメーターを伏せ、図が育ち、あとは眺めるだけになる。

加速42秒 → 最高速9秒 → 減速26秒 → 静止2.4秒 → 逆回転、を延々と繰り返す。
一周およそ2分40秒。加速の途上で錯視が順に立ち現れ、減速でそれを逆順に辿る。
どこかに触れるか、任意のキーで終了する。

## 技術

- Canvas 2D・単一 HTML ファイル・依存ゼロ・完全ローカル動作
- 残像は蓄積型:背景を不透明度 1−trail で塗り、その上に図を重ねる
- 鑑賞モードの進行はすべて実時間(秒)基準 — 60Hz でも 120Hz でも同じ速さで一周する
- モバイル:縦持ちは下部パネル、横持ちはパネルを右に寄せて図を左へ退避、safe-area 対応
- 鑑賞中は Screen Wake Lock で画面を消灯させない(対応ブラウザのみ)
