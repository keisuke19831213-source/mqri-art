# 環流 — Kanryū（2026-09-05・ccf5 art）

トーラスは、一つの輪をめぐる電流の磁場である。3月10日の「torus-art」（p5・形だけのトーラス）の作り直し。

## 物理
- 円電流（半径a）の磁場は Biot–Savart の閉形式：k²=4aρ/((a+ρ)²+z²)、B_z ∝ [K(k) + (a²−ρ²−z²)/((a−ρ)²+z²)·E(k)]/√((a+ρ)²+z²)、B_ρ ∝ z/(ρ√…)·[−K + (a²+ρ²+z²)/((a−ρ)²+z²)·E]。K,E は A&S 17.3.34/36 の多項式（誤差2e-8）を GLSL と JS の両方に同じ式で。
- **線の密度＝磁束**：磁力線はすべて輪の円板を通る。円板上で pdf ∝ |B_z|·ρ の CDF（256ビン）を JS で作り、GPU で逆引きして種を撒く。鉄粉と同じ密度になる（F で一様撒きと比べられる）。
- 粒子は RK4 で B̂ に沿って進む。刻みは導線からの距離で適応（0.06·d、下限0.0015）。速さ ∝ |B|^0.45。導線に触れたら撒き直す。
- 二輪（間隔=a）＝ヘルムホルツ：中心が一様。逆輪＝反ヘルムホルツ：中心がゼロのくぼみ（四重極）。**D で双極子近似**に切り替えると、遠くは同じで輪の近くが嘘になる（線が原点に吸い込まれる）。

## 描き方
- 粒子は 384²=147k、位置は RGBA32F のピンポン。**前フレーム位置との線分**（gl.LINES）を加算し、残像バッファ（減衰0.945）に溜める → ブルーム → ACES。点で描くと粒の雲にしかならない。
- 色：B_z>0（中心を昇る）＝暖、外を降りる＝冷。強さで明るさ。導線のそば（角距離<0.16）は抑える（露出が飛ぶ）。
- 彩3：夜／藍／金。明るい紙の版は負の露出で壊れたので外した。

## 罠
- 種を輪の縁（ρ→1）まで撒くと B_z の対数発散で縁に粒子が集まり白飛び → ρ≤0.94 で切る。
- 撒き直した瞬間の粒子は old→new の線分が跨ぐ（前位置が遠い）→ age が増えた粒子は描かない。
