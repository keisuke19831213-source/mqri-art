# 五つの箱 — Itsutsu no Hako（2026-09-05・ccf5 art）

三枚の黄金長方形から正二十面体、その双対の正十二面体に、五つの立方体と五つの正四面体が隠れている。4〜5月の platonic_ideal / プラトン立体_v1 の作り直し。

## 数学
- 正二十面体：(±1,0,±φ) の巡回置換＝互いに直交する三枚の黄金長方形（2×2φ）の角。辺 2、30辺。
- 正十二面体：(±1,±1,±1) と (0,±1/φ,±φ) の巡回置換。辺 2/φ、30辺。面の中心の向きは (1,0,φ) の族（二十面体の頂点＝双対）。
- 五つの立方体：(±1,±1,±1) を五回軸 (1,0,φ) まわりに 72° ずつ回す。全40頂点が十二面体の20頂点に一致し、**各頂点はちょうど二つの立方体に属す**。立方体の辺 2 ÷ 十二面体の辺 2/φ ＝ φ。
- 五つの正四面体：各立方体の二つの正四面体から同じ向きを一つずつ＝キラルな複合体。
- 右上にこれらをその場で検算（○／2）。

## 描き方
- 部品（長方形3・二十面体・十二面体・立方体5・四面体5）は中心から膨らんで登場（easeOutBack）、しぼんで退場。場面ごとに順送り（0.25秒ずつ）。辺＝光のカプセル、面＝半透明（黄金長方形と四面体）、十二面体の頂点＝珠。
- 自動で場面が巡る（12秒ごと）。タップで止める／進める。

## 罠
- 五回軸を (0,1,φ) にすると立方体の頂点が十二面体に乗らない（それは別の向きの十二面体の軸）。この座標では面の中心は (1,0,φ) の族。検算の「×」で気づいた。
