# ジターバグ — Jitterbug（2026-09-05・ccf5 art）

ベクトル平衡（立方八面体）は、八枚の正三角形が回りながら縮むだけで、正二十面体を通って正八面体に閉じる（Buckminster Fuller の jitterbug）。6月の polyhedral_orrery / metatron-crystal-lattice（多面体を並べただけ）の作り直し。

## 機構
- 立方八面体：12頂点 (±1,±1,0) の並べ替え。中心〜頂点 = 辺 = √2（＝ベクトル平衡の定義）。八枚の三角形は体対角線 n=(±1,±1,±1)/√3 を法線に持つ。
- 各三角形を自分の法線まわりに s·θ 回し（s = n の成分の積の符号：隣り合う三角形は逆向き）、中心へ h だけ寄せる：頂点 = h·n + R(n, sθ)·offset。三角形は剛体。
- 12の頂点はそれぞれ二枚の三角形に共有される。共有頂点が一致する h は |D(h)|² が h の二次式なので最小点で閉じた形に出る。全ペアで同じ h＝1自由度の機構。右上に「共有頂点のずれ」（2e-16）を検算として出す。
- **正二十面体**：θ＝22.240°。判定は「各頂点の5番目に近い頂点までの距離＝辺」（四角い隙間の短い対角線が辺と等しくなる瞬間）。中心〜頂点／辺 = 0.9511 = sin72°（正二十面体の外接半径の式と一致）。
- **正八面体**：θ＝60°。頂点が二つずつ重なって 6 点、中心〜頂点 = 1 = 辺/√2。ここで機構は閉じる（先は三角形が互いに貫く）。

## 描き方
- 辺＝板ポリのカプセル（加算）、面＝半透明の両面（フレネルで縁が光る）、頂点＝珠。深度で前後を整理し、ブルーム。
- 自動：平衡→二十面体→八面体→戻る を各段で止まりながら往復。Shift＋ドラッグ／二本指の横でたたむ・ひらく。

## 罠
- 二十面体の判定を「最近接＝辺」にすると θ=0 でも成り立ってしまう（辺は常に最近接）。5番目に近い頂点で判定する。
- 正四面体まで行く段階は、この機構（頂点ヒンジの剛体三角形）では 60° の先で三角形が貫くので外した。
