# SHIMMER — Thin-Film Iridescence & Glints

---

## 展示用キャプション

**SHIMMER — 薄膜のきらめきとグリント**
2026年／ジェネラティブアート（リアルタイム映像）
WebGL2 フラグメントシェーダー、単一 HTML

シャボン玉の膜、油膜、玉虫の翅、貝殻の内側——世界には「色を持たないのに色づく」表面がある。それは薄い膜の内と外で反射した光が干渉し合い、波長ごとに強められたり打ち消されたりして生まれる、構造色と呼ばれる現象だ。

本作は、その物理を光学モデルとして計算し、無数の微小な鏡片（グリント）のきらめきと重ね合わせる。光源が動けば干渉の色が波打ち、視線がずれれば表面全体が別の虹へと転調する。実体としての色ではなく、光と膜と角度の関係だけがつくり出す、掴めないきらめきを追う試みである。

マウスで光源を動かし、クリックで光の輪を放つことができる。

## 制作メモ

### コンセプト
- 「シマリング（shimmering）」= 掴めない、揺らぐ光のきらめきを主題とする
- 顔料の色ではなく**構造色**（薄膜干渉）を物理ベースで再現する

### 技法
- **薄膜干渉**：Airy 近似による RGB 波長別の位相計算（Belcour / Barla の研究に着想）
- **多スケール・ハッシュグリント**：微小鏡片の分布によるきらめき（Chermain に着想）
- ドメインワーピング fBm による下地の流動
- HDR mip ピラミッドブルーム ＋ ACES ＋ 色収差 ＋ グレイン

### 操作
- マウス：光源移動
- クリック：バーストリング
- Space：一時停止／S：PNG保存／F：フルスクリーン

### 制作上の教訓
- GLSL の `pow(x, 2.0)` は **負の x で NaN** を返す → 手動二乗（`x*x`）で回避
- NaN は mipmap を経由して**ブロック状に画面全体へ拡散**する。原因の特定が難しい典型例
- シーン FBO テクスチャは、パス1の前に必ず unbind しないとフィードバックループになる
