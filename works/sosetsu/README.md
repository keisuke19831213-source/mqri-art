# 相接 — Sōsetsu（2026-09-05・ccf5 art）

互いに接する四つの円。デカルトの円定理が、無限の円の曲率を整数で決める。4〜5月の recursive-bloom-apollonian（アポロニウスの花）の作り直し。

## 数学
- デカルトの円定理（1643）：互いに接する四つの円の曲率 k=1/r は (k₁+k₂+k₃+k₄)² = 2(k₁²+k₂²+k₃²+k₄²)。ゆえに k₄ = k₁+k₂+k₃ ± 2√(k₁k₂+k₂k₃+k₃k₁)。
- 複素デカルト（Lagarias–Mallows–Wilks 2002）：中心 z についても k₄z₄ = k₁z₁+k₂z₂+k₃z₃ ± 2√(k₁z₁k₂z₂+k₂z₂k₃z₃+k₃z₃k₁z₁)。
- 生成：四つ組 (a,b,c,d) から d を裏返す d' = 2(a+b+c) − d（曲率も kz も）。根が整数なら**全ての円の曲率が整数**（整数アポロニウス）。根 4 種：(−1,2,2,3)(−2,3,6,7)(−3,5,8,8)(−6,11,14,15)。
- 根の作図：外円（曲率 −n・中心0）、内円 A を x 軸上、内円 B は A と外円に接する与えた半径の円（二円の交点）、4つ目は複素デカルトで、三円すべてに接する解を選ぶ。

## 描き方
