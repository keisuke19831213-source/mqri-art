# 捩れ — Nejire（2026-09-05・ccf5 art）

二枚の生命の花を重ねて捩ると、大きな花が現れる。5月25日の「sacred_moire_engraving」（模様のモアレ）の作り直し。

## 数学・物理
- 六方格子（間隔 d）を ±θ/2 で捩って重ねると、モアレの周期は厳密に D = d／2sin(θ/2)（回転モアレ）。
- 整合角：cos θ = (3m²+3mr+r²/2)/(3m²+3mr+r²)（捩れ二層グラフェンの整合条件）。(m,r)=(1,1) 21.79°、(2,1) 13.17°、(3,1) 9.43°、(4,1) 7.34°、(5,1) 6.01°…。近づくと右上に表示。
- 1.1° は魔法角（Bistritzer–MacDonald 2011）。D ≈ 52d。
- 各層は解析 SDF（花＝六方格子の円、格子＝三方向の平行線）で描き、二枚の透明シートの**線の和集合**で塗る。重なった所は覆いが減る＝モアレは本物の仕組みで、画素より細くなっても平均として現れる（ジッタ蓄積で AA）。
- 包絡（E）：粗いぼかしを引いた帯域（DoG）でモアレの起伏だけを出す。`?probe=1` でぼかし後の一行の min/max/contrast を数値表示（6° で 0.109）。

## 見せ方の制約
- 花は線が多い（単位面積あたり弧長 2π/0.866 ≒ 7.3）。線幅が格子に対して太いと覆いが 1 を超えて灰色に溶ける。格子1単位が 30px 前後の寄りで見る（既定 zoom 2.2）。
- 魔法角は D=52d なので、線の少ない格子（3.5）に切り替えて 1単位≈14px にすると周期 ≈ 730px で一画面に収まる。花のままだと画面より大きい。

## 罠
- 加算で二層を塗ると全体が飽和して灰色になり、包絡も白飛びする。和集合（覆い）で塗り、包絡は DoG。
- 線幅の最小を「画素の 0.75」にすると寄りを引いた時に覆いが 1 を超える。0.6px・0.008 単位。
