# 水面 — MINAMO（ccf5-art・2026-08-29）

夕暮れから月夜へめぐる湖の水面。単一 index.html（WebGL2）自己完結。

- プレビュー: launch.json「ccf5-art」→ http://localhost:4820/art_minamo/
- `?warm=N` … 開始時刻をN秒に
- `?p=kagami|michi|nibi|shigure|tsukinagi|mahiru|iwashi|namari|nyudo` … きょうの表情を即時で呼ぶ（緩和スキップ・共有向き）
- `?s=haru|natsu|aki|fuyu` … 季節だけ指定（未指定はいまの月から）
- `?cam=高さm,俯角deg,向きdeg[,画角deg]` … 視線の指定（検証・構図の共有）。俯角-89〜+48・向きは全周・画角15〜75
- 刻のタイムライン（v3で一日化・1周=300秒）: **0=正午** / 〜80 ひるさがり / 85〜100 夕（季節で日没時刻が動く）/ 150=真夜中 / 200〜215 暁 / 230〜 朝。南中高度は季節から（夏70°/春50°/秋45°/冬28°）・太陽は東→南→西へ±49°動く
- 操作: タップ=波紋 / 1本指ドラッグ=視線（全周・真下-89°〜見上げ+48°） / ホイール・ピンチ=ズーム / 右下「調」=きょうの水面パネル
- 調パネル: 季節（春夏秋冬）・風0〜6.5m/s（凪=鏡面）・時のながれ×0.25〜4・刻スクラブ＋めぐり停止・目線の高さ1.2〜80m・ズーム×0.7〜×3.5・雲の量とかたち7種（巻/鱗/羊/綿/入道/層/霞）・水の肌（絹⇄硝子）・うねり・スリック・時雨
- デバッグ: `window.__seek(sec)` 時刻ジャンプ / `__step(n,fps)` rAFを介さずnフレーム / `__ring(x,z,amp)` / `__P` 状態

## 技術の柱（世界最高水準リサーチの応用）

1. **Tessendorf FFT 波浪**（映画・AAA標準）
   - JONSWAP（fetch制限・F=1500m）＋ 重力毛細管分散 ω²=gk(1+(k/kM)²), kM=363
   - 2カスケード: うねり L0=87m ＋ さざ波 L1=5.27m（バンドは log k の smoothstep で分割・境界二重計上なし）
   - 毎フレーム GPU 逆FFT: Stockham radix-2 のギャザー形（256²×16パス×2カスケード）
2. **Cox–Munk（1954）傾斜統計のグリッター**
   - 光の道は貼り絵でなく、σ²（平均二乗傾斜）∝風速 の Beckmann 分布 D×Fresnel から立ち上がる
   - σ² は「ガスト場」で局所変調 ＋ 距離でも増やす（サブピクセルの波をσに繰り込む＝グリッターのAA）
3. **突風の足（cat's paws）**
   - FFT水面は統計的に一様＝風のムラが出せない。→ さざ波カスケードの寄与（変位・傾斜・σ²）を
     低周波ガスト場 fbm(wp·0.021 − wind·t) で**シェーディング時に**空間変調する。
     風が撫でた場所だけ肌理が粗くなり、光の道の縁がゆらぐ。物理根拠は Cox–Munk の mss–風速線形則。
4. **分散性の波紋**（タップ/魚信）
   - 毛細管波は群速度＞位相速度。包絡はR=0.42τで走り、中の山は0.30τ——環の中で波が「後ろへ抜ける」
   - 法線勾配のみ解析的に加算（高さはレイキャストに入れない＝安定・十分見える）

## 実装の要点（再発見コストが高い）

- **Stockham ギャザー形**: 出力 index i、段スパン Ns で
  `b=i%(2Ns); hi=b>=Ns; bb=hi?b-Ns:b; j=(i/(2Ns))*Ns+bb;` 入力 x[j], x[j+N/2]、
  回転子 e^{+2πi·bb/(2Ns)}（逆変換は＋）。ビット反転不要・1シェーダで水平/垂直両用。
- **複素パッキング**: choppy変位 Dx, Dz は実信号なので P(k)=Dx(k)+i·Dz(k) を1複素場に詰め、
  IFFT一回で re=dx, im=dz。RGBA = (高さ複素, P複素) で 1テクスチャ2FFT同時。
- **kレイアウトは非シフト**（m<N/2→m, else m−N）にすると出力の (−1)^(x+y) 市松補正が不要。
- **時間は状態を持たない**: h(k,t)=h0e^{iωt}+h0*(−k)e^{−iωt} なので巻き戻し・早送り自由。
  ?warm も __seek もただの時刻代入。非表示タブの追いつき処理が一切不要になる設計。
- **風変更のポップ回避**: 乱数ξはtexel決定的ハッシュ→風が変わっても位相は連続、振幅包絡だけが
  滑らかに変わる。h0再生成は256²×2パスなので毎フレームでも無料。
- **グリッターのちらつき対策**: 法線は変位テクスチャの有限差分だが、LOD＝footprint/texel で
  textureLod（要 generateMipmap 毎フレーム）。遠方は mip が傾斜を均し、σ²の距離項が引き継ぐ。
- **夕日の見得**: 沈む直前に日輪を大きく（角半径0.0052→0.0126rad）・赤く。lowS=1−smoothstep(0.02,0.12,sunDir.y)。
- **グリント消灯バグ回避**: 太陽高度での geo フェードを絞りすぎると日没の一番美しい道が消える。
  smoothstep(0.004, 0.045, L.y) 程度に。
- **カメラ行列の符号罠**: 列=［right, up, fwd]で fwd=(0, sinPitch, cosPitch)。転置を渡すと
  「下向きピッチのつもりが上向き」になり水面が消える（今回一度踏んだ）。
- Bloom はシリーズ既知の掟どおり: ダウンサンプルUVは**dstテクセル**基準・アップサンプルは加算(ONE,ONE)。
- 適応解像度: rAF間dtのEMA（dt>80msは除外）・閾値はvsync床より上（19.5ms↓/17.2ms↑）。

## 表情モード（8/29晩の増築）で学んだこと

- **凪＝鏡面は「風は自分より速い波を起こせない」から出る**。JONSWAPのω⁻⁵裾は風を弱めても
  2〜3割しか痩せず、スライダーだけでは絶対に鏡にならない。生成条件 c(k) < U をスペクトルに掛け、
  さらに**有効風速 Ug = U − 0.22**（ビューフォート0）にシフトして毛細管極小（cph≈0.23m/s）の帯も締める。
  これで凪の夜は星が水面に映る。
- **罠: 緩和パラメータ×変化閾値は「尻尾で凍る」**。h0再生成を「|ΔU|>0.004のとき」にすると、
  指数緩和の1フレーム変化が閾値を割った瞬間から永遠に再生成されず、U≈0.57相当で固まった。
  再生成は毎フレーム無条件に（256²×2パス=無料）。
- **罠: ブラウザペインの「タブ非表示」と「ペイン自体の非表示」は別物**。ペインが隠れると rAF=0fps で
  スクリーンショットも「最後に提示されたフレーム」しか写らない。tabs_context の
  「The Browser pane is currently hidden」が手掛かり。対策=状態を即時スナップするURLプリセット
  `?p=` を用意して1フレーム目で完成した画を出す（時雨は過去5秒ぶんの雨紋をプリシード）。
- 曇天は「直達光を落として周囲光を持ち上げ、彩度をそっと抜く」の三点で鈍色になる。
  雲は すじ(anisotropic fbm)/うろこ(billow=1−|2f−1|)/しとね(低周波・天頂まで) の3場を量でせり出す。
- 時のながれは simT への dt×2^flow 積算に変更（解析的時間はそのまま＝巻き戻し可能）。
  ペインが隠れている間は作品も眠る（dtクランプ0.25sで復帰ジャンプなし）。

## 自在カメラ（8/29夜の増築）で学んだこと

- **真下視は「フレネルが消える」**＝反射がほぼゼロになり定数色の水体だけが残ってのっぺりする。
  上から見た水面の表情は反射でなく**傾きの陰影**＝勾配の太陽方向成分 stripe=dot(−grad, sunH) を
  水体色に掛ける（俯角が深いほど増幅・clamp 0.60〜1.45。強すぎると革の型押しになる——×16は革、×4.5が水）。
  時雨を真上から見ると雨紋の同心円が読めるのはこの陰影のおかげ。
- **罠: float32のハッシュは大入力で崩壊する**。星セルを3D化して `cell.z*57.31` を足したら入力が±8000級になり、
  hash内の `p*851` → fract の精度が1/8刻みまで落ちて星が全滅した。**最初に fract(p*0.1031) で畳む
  Hoskins型 hash13** なら入力の大きさに強い。「ノイズが壊れたらまず入力の大きさを疑う」。
- **3Dセルの点＋球面シェル**は、シェルが点の脇を素通りして密度が1/10に落ちる。
  接平面距離（dd から視線方向成分を除く）で測れば、シェルがセルのどこを通っても星は光る。
- 星の方位グリッド（az,el）はヨー全周にすると az=±π に継ぎ目が出る——3Dセル化が正解（上の2つの罠とセット）。
- 雨と魚信は「見ている場所」（fwd と水面の交点 lookAtXZ）に降らせる。カメラが自由になった瞬間、
  固定の正面に撒く演出は全部破綻する。
- ズームは画角で（fov 15〜75°）。ドラッグ感度は fov/52 でスケール＝望遠でも指の速度が一定に感じる。

## v3（8/29深夜）: 一日・季節・雲七形・水の肌 — リサーチ準拠

- **一日化**: 刻は正午基準の余弦弧 e=A·cos(φ)+B。南中高度＝季節（SEASONSのeNoon）。
  **太陽方位の振れは±49°に抑える**——±83°にすると日没の太陽が定番構図から外れて「光の道」が消える。
  太陽を追うプリセットは preset に yaw を持たせる。月の弧は低く上限14°（月の道の美学＋フレーム内）。
- **昼の空**: レイリー勾配（zenDay/horDay）＋ミー前方散乱の白い暈（霞むほど広い）。
  crisp（空気の乾き）で青の深さ＝秋晴れの紺。曇天は直達を落とし彩度を抜く従来系と連続ブレンド。
- **雲七形**（十種雲形の見た目本質を7つに圧縮）: 巻=ドメインワープした絹の筋 / 鱗=高周波billow(1−|2f−1|) /
  羊=低周波billowをpowで締める / 綿=高閾値の点在パフ / 入道=方位シルエット関数（**多峰ガウス×fbm縁**を
  仰角と比較・上ほど白く底は灰） / 層=低周波かぶせ / 霞=低コントラストのヴェール＋uHaze加算。
  **立体感は「太陽側の場をもう一度サンプルして差分」**＝日向の峰と日陰の底が出る（2サンプルで擬似自己陰影）。
  かたちは float 連続値で隣接形をmix＝切替がとろける。
- **季節**: eNoon・crisp・haze・水の色・雲の基準量と既定形（春=霞/夏=綿/秋=鱗/冬=層）。
  `scur` に向かって空気がゆっくり入れ替わる（緩和0.4/s）。
- **水の肌**（実物リサーチ準拠）:
  - 絹⇄硝子 = σ倍率(2.2→0.5)×距離σ(1.35→0.45)×チョップ(0.6→1.35)×毛細管ゲイン(1.45→0.85) を1本に束ねる
  - **スリック** = 天然界面活性膜が毛細管波を殺す実在の鏡の帯（windrows・風向きに平行・凪で顕著・
    傾斜分散~50%減の観測）。風向き座標系の異方性ノイズで帯を作り gW とσ² を局所的に落とす
  - **うねり** = 局所風と無関係な遠方スウェル（λ26m狭帯域・c(k)<U生成条件の外なのでバイパスして加算）
- 罠: プリセットの空の時刻は**タイムライン変更のたびに全部引き直す**（旧値は別の時間帯を指す）。
