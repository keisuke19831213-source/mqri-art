# 糸かけ — Itokake（2026-09-05・ccf5 art）

釘を打ち、素数の歩幅で糸を掛ける。内側に浮かぶ円は一本も描いていない。5月26日の sacred_thread_observatory（糸の模様）の作り直し。**表現を変える回**：木の板・真鍮の釘・木綿の糸を Canvas 2D で工芸の質感に寄せ、糸が一本ずつ巻かれる時間を見せる。

## 数学
- 等歩：n 本の釘を円に打ち、i → i+s と掛ける。弦の包絡線は半径 R·cos(πs/n) の円。歩幅を素数にすると輪は gcd(n,s)=1 で一筆になる。大きい素数から順に重ねると（64 本なら 31・29・23・19・17・13・11・7）内側から外側へ円が層になる＝素数糸かけ曼荼羅。
- 掛け算：i → k·i (mod n)。包絡線は尖点 k−1 のエピサイクロイド（k=2 カージオイド、k=3 ネフロイド）。円 R に内接し、転がる円の半径 R/(k+1)、土台の円 R(k−1)/(k+1)。尖点は釘 0 の向き。
- Z で包絡線の予言を点線で重ねる（等歩＝円、掛け算＝エピサイクロイド）。

## 描き方
- 板：放射グラデーション＋揺らぐ縞で木目。釘：影・真鍮の胴・頭の光。糸：影・芯・光る稜の三本重ね（太さは画面比）。掛け終えた糸はオフスクリーンに溜め、巻いている一本だけ毎フレーム描く。釘の頭は糸の上。
- 掛け算は k ごとに「巻く→3.5秒見せる→ほどく→次の k」。素数は層を重ねて巻き終わり。

## 罠
- `?warm` を初期化直後に回すと、レイアウト確定のリサイズで糸が解ける → 3フレーム目に巻く。
- エピサイクロイドの尖点は θ=0 で x 軸方向に出る。釘 0 を上に置くなら −90° 回す（(x,y)=(Y0,−X0)）。
