# 朔望 ─ SOL TERRA LVNA

太陽・地球・月、三体の運行を時を操りながらながめるインタラクティブなデジタルアート。
「[星の運行 ─ MOTVS STELLARVM](https://github.com/keisuke19831213-source/motus-stellarum)」の姉妹作。
単一HTMLファイル・依存ゼロ・ビルド不要。

描かれる運行は本物です。地球はJ2000平均軌道要素のケプラー軌道、月は主要摂動項つきの
略算(黄経 ~0.2°・黄緯 ~0.1°)で位置を求めており、月齢・満ち欠け・食の日付は実際の暦と
対応します。初期状態は「今日」。

## 見えるもの

- **めぐりの絵** — 太陽を中心に地球がめぐり、月が地球にまといつく銀の三つ編みの軌跡
  (月の軌道だけ40倍に誇張。画面にも明記)
- **月の窓** — 磨いた銀の円に、正しい欠け際(ターミネーター)だけで見せる意匠。
  満ちるほど月暈がひろがる。月齢・輝面比と、三日月・十三夜・立待月・有明の月…といった **月の和名**
- **潮** — 朔望で「大潮のころ」、弦で「小潮のころ」。地球のまわりの潮のふくらみも月を向く
- **食** — 三体がひとすじに並び月の黄緯が小さい日に「日食のころ」「月食のころ」。
  月食の月は赤銅色に、日食の新月は細い光冠をまとう

## 操作

- **よこにドラッグ** ─ 時を送る・巻きもどす / **ホイール・ピンチ** ─ 遠近
- **次の朔・次の望・次の食** ─ その瞬間へ跳んで、とまる
- スライダーで時の速さ(一秒に約1時間〜160日)、Space で停止/再開、星にふれると名と距離

## 精度について

食の判定は「朔望の瞬間に月の黄緯が限界(日食1.35°・本影月食0.95°)より小さいか」で行う。
2026–2028年の実際の食(2026-02-17・08-12日食、03-03・08-28月食、2027-02-06・08-02日食、
2028-01-26日食、07-06月食)との一致を確認済み。半影月食は対象にしていない。
ごく際どい部分食は判定から漏れることがある。

## 開発

```bash
python3 -m http.server 8000
```

`index.html` を開くだけでも動きます。外部リソースへの通信は一切ありません。
