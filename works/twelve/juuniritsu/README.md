# 十二律 — 音の円環は閉じない

> **v1.2（8/22追補）＝「並び・五度圏」モード新設**：十二平均律の盤＝サークル・オブ・フィフス。全12調の長調（C〜B・英名）＋調号（♮/♯1〜♯6=♭6/♭5〜♭1）＋内輪に平行短調（Am〜G♯m）を正立表示。F♯=G♭の異名同音の継ぎ目には、調律が平均のとき「とじた」・純正のとき「とじない」の金字——**十二律（純正の積み重ね）が閉じ残した環を、十二平均律（誤差の十二等分）がとじた**という両者の関係が盤上で切り替わる。中央にいまの調（例：ニ長調（D）調号♯2 平行短調Bm）と平均律のことわり。初期表示は `?lay=c`。罠＝この作のVARIANTSにはaccentフィールドが無い（後年の作と異なる）——流用時は色を直書きする

## 展示用キャプション

**十二律**
2026年／ジェネラティブアート（インタラクティブ映像・音）
WebGL2 夜気シェーダ ＋ 2Dキャンバス円環 ＋ WebAudio、単一HTML

ひとつの光点が、十二の音を五度ずつ歩いてゆく。
歩いた跡は弦になり、弦の重なりは星形十二角形を彫る。
けれど純正の五度で十二歩あるくと、円は元の場所に戻らない——
ピタゴラスのコンマ、23.46セント。人類が「円」と呼んだものは、実は螺旋だった。
音の名は日本十二律（壱越・断金・平調……）。並びを替えると、
同じ十二の音が半音の環から五度の環へ、席を立って歩き直す。

## 制作メモ

- **シリーズ**: 「12」— 円環の連作　第一作。企画の正= vault `02_Projects/260822_「12」円環アートシリーズ_企画.md`
- **コンセプト**: 駆動原理＝生成元の歩み。12と互いに素な 1,5,7,11 だけが12点すべてを巡る。歩みは星形多角形 {12/g} を彫る。純正調律では1周（12歩）ごとに+23.46¢ズレて足跡の半径が伸び、螺旋になる（シリーズ法則5「円は閉じない」の第一実装）
- **技術構成**: sekki-circle（環・二十四節気）の骨格を継承——WebGL2フルスクリーン三角形＋Canvas2Dリング＋rAF一本・放射方向縦書き・仕上げ3点（ビネット→グレイン→トーンマップ）。音はWebAudio（triangle+sine倍音・lowpass・2.1s減衰）。純正/平均は歩み1歩のセント値（701.955 vs 700）の違いだけで実装＝物理が演出を書く
- **インタラクション**: ドラッグ=環を回す／クリック=その音へ跳んで奏でる／並び=半音環⇄五度環モーフ／歩み=五度・四度・半音・逆行／調律=純正⇄平均／空白=停止
- **例外ノード（法則4）**: 五度圏の底＝異名同音の継ぎ目（下無 F♯）。半音環と五度環で唯一、対極の席が入れ替わらない音
- **見た目3案**: ページ内「見た目」ボタンで夜奏（藍夜・既定）→分光（漆黒に十二色相）→墨明（墨に朱金）を循環切替（切替時は足跡の弦も新しい衣に染め直す）。初期指定は `?v=A|B|C`
- **検証**: `?warm=N`（N秒ぶん過去時刻で歩ませてから開く。未来時刻に置くと脈動が壊れる罠を踏んだ）・`?lay=5`（五度環で開始）・`window.__juuni={set,get,step}`
- **踏んだ罠**: ①GLSL識別子に非ASCII文字（IME由来）が混入するとコンパイルは通らない ②warmの歩み時刻を未来に置くとフェード/脈動計算が全部暴走する（過去時刻で歩ませる） ③縦書き律名は「外周から内へ」読み下ろす順で置く（sekki-circleと同じ、内から外だと逆読みになる）
- **周回の定義**: コンマの1周は「12歩＝全音を一巡」。オクターブ数（steps×g/12）で数えると螺旋が12倍速で暴走する
- **配信**: launch.json「ccf5-art」(:4820) の `/12_01/`。作品差し替えはBash側rsync
