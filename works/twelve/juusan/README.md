# 拾参 — 一段うえの、一

## 展示用キャプション

**拾参**
2026年／ジェネラティブアート（インタラクティブ映像）
WebGL2 北天シェーダ ＋ 2Dキャンバス螺旋、単一HTML

真上から見おろしているあいだ、世界は完全な円で、1と13はおなじ点に重なっている。
指でかたむけたとき、円がじつは螺旋を真上から見た影だったことがわかる。
十三番目の真珠は、一番目のちょうど真上——一周ぶんの高さをもった、あたらしい1。
螺旋は19めぐり。228の月に、金の閏が7つ埋まって235——メトンの環。
12は、世界をひと巡りに変える器。13は、ひと巡りした記憶をもった、つぎの1。
連作十二作にひそめてきた「閉じない円」の署名を、はじめて主役に立てた一作。
12は秩序、13は再生。

## 制作メモ

- **シリーズ**: 「12」— 円環の連作　**拾参・十三番目の扉**（全12作+結のあとに生まれた13作目＝作品の存在そのものが「繰り上がり」を演じる。名は第十二作・十二型の「拾参ノ型」から）
- **駆動原理（シリーズ内で唯一）**: **視点のかたむきが主変数**。tilt=0で真上の眼（円・mod 12の世界・時計の嘘）→上下になでると螺旋がひらく。円は螺旋の影、という一点をひとつのジェスチャーに凝縮
- **構造**: 19周×12=228の真珠＋金の閏7粒＝235（メトン周期 235朔望月≈19太陽年）。閏は章法の置閏年 {3,6,8,11,14,17,19} の年末に半歩ずらして挿入。ドの柱（1・13・25…）がわずかに明るく、真珠13番は常時またたく（最初の繰り上がりの席）
- **13の四つの顔**（本人ノート「12と13」の整理）: 越境=半音階の一歩／繰り上がり=ドの柱をまたぐ瞬間の縦糸と閃き／補正=金の閏真珠＋メトンのカウンタ／中心=北辰タップで「中心の眼」カードが開く（→次作「十二のくちづけ」への扉。深掘りはすべて次作へ＝判定済み）
- **音**: **シェパード・トーン**（オクターブ7層×釣鐘包絡・C4峰）——のぼりつづけるのに還ってくる聴覚の螺旋（Pitch Helix / Shepard 1964）。疾くのときはドの柱だけが鳴る＝いつまでも高くなりつづけるおなじ音。閏はわずかにデチューンした長い鐘
- **わたしの日（誕生日の螺旋・同梱＝判定済み）**: 日付を入れると 各周=一年・各真珠=ひと月 の螺旋に組み替わる。毎年おなじ日が金の真珠になって縦に積みあがり、点線の糸でつながる。「おなじだが、おなじではない」の体感装置。既定値=1983-12-13（月の12×日の13＝例外ノード・法則4）
- **例外ノード（法則4）**: 12月13日（既定のわたしの日）と、真珠13番のまたたき
- **閉じない円（法則5）**: 本作は法則5**そのもの**——全作の隠し署名（一周0.3°のズレ）を主役化した作品
- **見た目3案**: 北辰（藍×銀・既定）→熾（火の暗がり×琥珀）→墨（無彩）。`?v=A|B|C`・`?tilt=かたむき`（×90°・0=真上/1=真横/2=裏の眼/4=一回転・無限にまわる）・`?p=連続角`
- **視点の円環（赤ペン2・3）**: かたむきは0〜360°を無限回転——真上の円→螺旋→裏の眼（さかさの円）→宙返り→はじめの空へ。**観る者の視点もまた円環**（歩む光はつかんでいても止まらない）
