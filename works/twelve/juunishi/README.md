# 十二支 — 六十年でひとめぐり

## 展示用キャプション

**十二支**
2026年／ジェネラティブアート（インタラクティブ映像）
WebGL2 夜気シェーダ ＋ 2Dキャンバス歯車盤、単一HTML

外の盤は十二支——方位であり、刻であり、年である三重の目盛。
内の輪は十干。年がめぐるたび、年の針はひとつ進み、
十干の輪は6°だけ滑る。ふたつの歯車が同じ席で出会うのは60年に一度——還暦。
盤のなかを、ほんものの木星（歳星）が11.862年でめぐってゆく。
暦の理想（12年）と星の実際はすれ違いつづけ、約86年で一支ぶんずれる。
古代の暦官はこれを「超辰」と呼んで補正した。円は、ここでも閉じない。

## 制作メモ

- **シリーズ**: 「12」— 円環の連作　第三作。企画の正= vault `02_Projects/260822_「12」円環アートシリーズ_企画.md`
- **駆動原理**: 10×12の歯車。主変数は「年」一本。十二支盤は固定（子=真北＝方位盤・刻盤・年盤の三役）、十干輪が年-6°の滑り（60年で一周＝還暦）。**年針が次の支に着く瞬間、次の干がちょうど滑り込んで整列する**（干支のペアは整数年で厳密一致・年内は歯車らしくすれ違う——連続性は式で検算済み）
- **閉じない円（法則5）**: 歳星の超辰。木星の実周期11.862年 vs 暦の理想12年。太歳（金の点・理想）と歳星（蒼白の点・実際）が内側の軌道をめぐり、年0.349°ずつ離れて約86年で一支ぶんずれる（劉歆の暦を実際に悩ませた史実）。中央にずれの実測値
- **例外ノード（法則4）**: 卯をタップすると兎が**猫**になる（ベトナムの十二支）。十二支は「スロットの中身を差し替えられる書き換え可能なOS」であることの実装
- **法則3**: 三合の局＝正三角形×4（申子辰水局・寅午戌火局・巳酉丑金局・亥卯未木局、五行色）。今年の支の局だけ明るい。支冲の直径6本・**鬼門の軸**（丑寅↔未申・破線・呼吸）
- **和時計**: 刻の針はほんものの現在時刻を指す（子の刻23-1時…真夜中0時に針は真北）。目盛は60（干支六十年と刻の分節の二重読み）
- **中央**: 干支（丙午）・読み（ひのえうま）・五行陰陽×動物・西暦・甲子からN年目/還暦まであとN年・歳星のずれ。支をタップ→語源（植物の一生：滋→紐→演→…→核）と刻・動物
- **見た目3案**: ページ内切替＝漆金（漆黒×金・既定）→朱華（朱塗）→藍白（藍磁）。`?v=A|B|C`・`?year=` で開始年指定可
- **v2 本気モード（8/22赤ペン反映）＝解説の間**: 支をタップで開くカード。①**歌川国芳・十二支の揃物 全12枚**（国立国会図書館デジタルコレクション／パブリックドメイン）をリサーチして設置（contain表示・出典スクリム・`img/`同名上書きで差し替え可）②刻・方位・**旧暦の月**（子=十一月〜亥=十月の建月）③**三合の局と冲**をその支の視点で表示（例：未→三合 亥卯未・木局｜冲 丑）④語源（植物の一生）⑤民俗の書き下ろし（大黒天の鼠・撫で牛・毘沙門の虎・因幡の白兎・雨乞いの龍・弁財天の蛇・絵馬の起源・三猿と庚申・鳥居の長鳴鳥・戌の日の帯祝い・摩利支天の猪…）＋ベトナムの差し替え（猫・水牛・山羊・豚）⑥卯タップは猫の顕現と連動
