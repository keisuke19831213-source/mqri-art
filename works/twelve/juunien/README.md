# 十二縁 — この環だけは、閉じないことが救い

## 展示用キャプション

**十二縁**
2026年／ジェネラティブアート（インタラクティブ映像）
WebGL2 香煙シェーダ ＋ 2Dキャンバス多重円環、単一HTML

外縁は十二因縁——無明にはじまり老死にいたる、苦しみの因果の環。
中心では三毒（貪・瞋・癡）が互いの尾を追い、環をまわす動力になっている。
縁の川は「老死に縁りて、無明生ず」と、際限なくめぐりつづける。
けれどこの環には、ただ一箇所だけ切れ目がある——受と愛のあいだ。
感じることは避けられない。しかし渇くかどうかは、そこで決まる。
門に触れれば、愛から順にひとつずつ環は滅び、寂（しじま）がおとずれ、
環のそとの月だけがのこる。それでも無明はふたたび目をさます。
シリーズを貫く「閉じない円」は、この作品でだけ意味が反転する——
閉じないことが、救いである。

- **断ち切りの物語（法則4＝例外は「点」でなく「切れ目」）**: 受(6)と愛(7)のあいだの門（呼吸する二重の刻み）をタップ、または「断つ」ボタン→**愛から順に環がひとつずつ滅び**（「愛、滅す」「取、滅す」…）→**寂**（全灯消え・環のそとの月だけが輝く・6.5秒）→**無明からふたたび**（「無明、ふたたび」…環が順に再燃）→流転へ戻る。約26秒の一幕
