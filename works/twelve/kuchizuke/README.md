# 十二のくちづけ — 触れるのは、十二まで

## 展示用キャプション

**十二のくちづけ**
2026年／ジェネラティブアート（インタラクティブ映像・音）
WebGL2 一条の光シェーダ ＋ 2Dキャンバス疑似3D球、単一HTML

同じ大きさの球に、触れられる球はちょうど12個——3次元の接吻数。
ふしぎなのは、12個ならべてもまだ余白があることだ。
球たちは中心に触れたまますべり、位置を入れかわることさえできる。
だからグレゴリーは1694年、「13個いけるのでは」と考えた。答えの証明は1953年——260年後。
十三個目の幽霊を押し込むと、12個は場所をゆずって動く。動くのに、入りきらない。
画面の「あと何度足りないか」は幾何学の実測であり、演出ではない。
そして中心の眼——うちから見れば、まわりに12、中心に1、あわせて13。
13は外の数ではなく、12をひとつの全体にする中心かもしれない。

## 制作メモ

- **シリーズ**: 「12と13」二部作の**第二作（空間の13）**。第一作=拾参（時間の13・螺旋）。拾参の北辰タップ「中心の眼」カードがこの作品への扉。思索の正=本人ノート「12と13」§10-11
- **駆動原理（この作品の発明）**: **球面上の位置ベース物理**。12球は単位ベクトル、接触角60°（sin(θ/2)=r/D=1/2）を制約に毎フレーム緩和。初期配置=正二十面体の12頂点（隣接63.43°＞60°＝**遊隙が実測で存在**）。つかんでころがすと、触れたまま動けること＝殻が閉じないことが手でわかる
- **グレゴリーの幽霊（例外ノード・法則4）**: 十三個目は制約の重みが非対称（球はゆずる.72／幽霊は粘る.28）。緩和後に残る侵犯角＝**ニュートンの正しさの残差**をそのまま「あと n° 足りない」と表示。押すと12個が本当に場所をゆずる（遊隙）のに、どこまでも入らない——kissing number 12の証明（Schütte & van der Waerden 1953）が指にこたえる
- **三つの間（v2＝身振りと訪れでひらく・ボタンは置かない）**:
  - ①**くちづけ**＝到着シーケンス。等間隔をやめ、拍にためらいを入れた（間合い760〜1520ms・終盤は間が深くなる）。各球は席から60〜110°離れた入口から**曲線で漂いつき（slerp）・触れる直前にためらい（1.24→1.12でひと呼吸）・そっと settle**。触れた瞬間＝鐘＋**接点に波紋**＋**中心の球が息をする**＋球が灯る。十二個目のあとに**とじの和音**（根・五度・オクターブのアルペジオ）
  - ②**グレゴリーの幽霊**＝初回は**招かれざる客として自分から訪れる**（完了の15〜21秒後）。訪れたあとは**じぶんで殻のうえをすべり、最小隙間を最大化する方角を実計算で探しつづける**（52方位サンプリング）。つかんで押し込める・**強く放り投げると闇へ帰る**（この場合34〜56秒後にまた来る）。**序章が終わるとボタン「幽霊を呼ぶ⇄帰す」が現れる**（v4・赤ペン）——ボタンで帰した場合は意思を尊重して勝手には戻らない。物語の一拍目（初回の訪れ）と鑑賞者のコントロールの両立
  - ③**中心の眼**＝ボタンでなく**奥へ潜る**（ホイール/ピンチのズーム・Z>2で殻をくぐって内側へ・手前に引けば戻る）。Z≈1.5で「そのまま奥へ——」のささやきが一度だけ出る。魚眼の空（視野130°・12球の視角半径30°=sin α=1/2の実値）
- **美の層（v3・赤ペン「アートとしての美しさ」への応答）**:
  - **真珠の質感**＝一条の光（左上）の広いハイライト＋**小さく強い鏡面のひかり（ブルーム付き）**＋影がわの**冷たいリム**（環境の照り返し・青白）＋光がわの**あたたかい虹の気配**（アクセント色の弧）
  - **接触の影**＝球どうし・球と中心の触れ目に暗いくぼみ（オクルージョン）——「触れている」重さは影が語る
  - **十二の淡彩**＝各真珠に半音ぶんの色をひとしずく（hsl 30°刻み×14%・玄テーマでは無彩を守るため0）
  - **舞台**＝後光（群れの背後の光だまり）＋**光塵42粒**（一条の光の柱の中で明るくまたたく・奥と手前の二層）＋**息をするカメラ**（pitchが周期9秒で±1°ゆらぐ）
  - **中心の球**＝内側からの微光（みずから灯る一）・「一」の字に金のにじみ
  - **幽霊**＝けむりの球（うちに淡い光・息の破線・拒まれの熱で緋に染まる）＋**さがした跡**（殻のうえに銀の点々が6.5秒で消えてゆく）
- **音**: くちづけの鐘（球i=半音i・倍音2層・70msレート制限）・幽霊は低いthud。12球の殻そのものが楽器
- **ことばの呼吸**: 下部のことばは出来事で目ざめ、5秒の静けさで34%まで退く（作品がひとりで呼吸する時間をつくる）
- **閉じない円（法則5）**: 遊隙。殻は剛体でなく、配置は一意に定まらない——「閉じないから、うごける。うごけるから、こわれない」
- **中心は動かないもの**: 中心の一球（「一」の字・不動）
- **UIの掟（赤ペンからの学び・8/23）**: **UIは作品の文法から導く**。時間軸のないこの作品に三連ボタン（止/ゆるり/疾く）を継がない（削除・自転は微速固定）。部屋の入口を設定ボタンにしない——幽霊は「訪れ」・中心の眼は「潜る身振り」。ボタンは3つだけ（音・いわれ・見た目）
- **見た目3案**: 真珠（夜×白真珠・既定）→蜜（暖・琥珀）→玄（無彩）。`?v=A|B|C`・`?yaw=`
- **いわれ**: 接吻数・ニュートン=グレゴリー・遊隙・次元の梯子（1D:2 / 2D:6 / 3D:12 / 4D:24 / 8D:240 / 24D:196,560・5-7次元は未解決）・文化の12+1（構造の相似として）
- **検証フック**: `window.__kuchi={get,skip,setGhost,setEye,setView,setZ,pushGhost}`
- **罠**: ピンチは指の台帳（Map）で管理し、primary pointerdown時に台帳をクリアして自己修復（[[pointer-bookkeeping-self-heal]]方式）
- **配信**: launch.json「ccf5-art」(:4820) の `/12_14/`
