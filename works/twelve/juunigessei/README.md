# 十二月精 — 杖をもつ月だけが、季節を統べる

## 展示用キャプション

**十二月精**
2026年／ジェネラティブアート（インタラクティブ映像）
WebGL2 森夜シェーダ ＋ 2Dキャンバス焚き火と精霊、単一HTML

雪の森の奥で、十二人の月の精が焚き火をかこんでいる。
冬の月は老人、春の月はいちばん若く、夏は青年、秋は壮年——
一年はひとつの生涯であり、環をめぐるたびに若がえる、不老の輪。
杖をもつ月だけが季節を統べ、杖がわたるたび炎は高く燃えて世界の色が変わる。
「奇跡」にふれれば、スラブ民話のあの夜——
一月の杖が三月へ、六月へ、九月へと環を跳び、
雪のなかに、すみれが、いちごが、りんごが、順にひらく。
環の外にはいつも、十三人目——人間の娘が火にあたっている。

## 制作メモ

- **シリーズ**: 「12」— 円環の連作　第九作。企画の正= vault `02_Projects/260822_「12」円環アートシリーズ_企画.md`
- **駆動原理**: 杖のトークン巡回。ひとりが統べ、十一人が待つ——「アクティブな1要素が円周を移動する」型の原型（親指ポインタと同型）。杖がわたる瞬間に炎がフレアし、背景の季節の粒（雪・花弁・光虫・落葉）がなめらかに入れかわる
- **焚き火**: 粒子の炎（40粒・上昇＋ゆらぎ＋しぼみ・lighter合成）。**炎の色が季節**＝冬は白青、春は若緑、夏は橙、秋は金褐。薪3本と地明かりのグロー
- **月の精**: 頭巾の座像（面で組む・掟どおり）。チェコ語の月名と語源（Leden=氷／Únor=沈む／Březen=白樺／…／Prosinec=願う）。**齢の四層（法則1＝4×3）**：冬=老人・春=最年少の若者・夏=青年・秋=壮年——環をめぐって若がえる不老の輪。統べる月は王座の石にすわり、金の杖をもつ
- **奇跡の一幕（約23秒）**: 民話の筋そのまま＝一月→三月→六月→九月→一月の**とび石**（環に弦が残る・法則3の変奏）。各段で炎が季節色にフレアし、すみれ・いちご・りんごの言葉がともる。「礼をつくす者に、季節はひらく」
- **例外ノード（法則4）＝十三人目**: 環の外、森のふちにいつも小さく人間の娘がいる（ふだんは気配・奇跡と注視で明るく）。「環はいつも、外にひらいている」
- **閉じない円（法則5）**: めぐった年の数（lap）が各精霊の面差し（目のひかり・頭巾の色）をわずかに変える——**めぐってきた一月は、去年の一月ではない**
- **インタラクション**: 月の精をタップ＝杖がその月へわたる（たのめば、ゆずってくれる）／統べる月をタップ＝語源の詳細／娘をタップ＝十三人目の話／止・ゆるり(9秒/月)・疾く(2秒/月)
- **見た目3案**: 焚夜（藍黒の冬夜・既定）→雪原（月明の青）→樅森（深い緑）。`?v=A|B|C`
- **検証フック**: `window.__gessei={pass,miracle,get}`
