# 十二色 — まざれば、灰にとける

## 展示用キャプション

**十二色**
2026年／ジェネラティブアート（インタラクティブ映像）
WebGL2 画廊シェーダ ＋ 2Dキャンバス色相環・加法の花びら、単一HTML

イッテンの十二色相環は、絵ではなく計算尺である。
環に内接する図形——直径・正三角形・正方形・六角形——を回すだけで、
あらゆる調和の配色がひとりでに生まれる。
選ばれた色は光の花びらとなって中心へ寄り、つりあった和音は灰にとける。
イッテンはそれを、調和と呼んだ。
そして環の底には、金継ぎのすじ——赤紫と紫は、虹のどこにも無い色。
光のスペクトルは線であって、環ではない。
目のなかで発明されたその継ぎ目だけが、環をとじている。

## 制作メモ

- **シリーズ**: 「12」— 円環アートの連作　第八作。企画の正= vault `02_Projects/260822_「12」円環アートシリーズ_企画.md`
- **駆動原理**: 回る内接多角形が配色を生む（イッテンの計算尺の実装）。和音5種＝補色（直径）／三和音（正三角形）／分裂補色（二等辺）／四和音（正方形）／六和音（六角形）。位相が主変数で、多角形がゆっくり回りつづける
- **まざれば灰**: 頂点の色は加法（lighter合成）の花びらとなって中心へ寄る。**灰の判定は色相ベクトルの合力**（RGB平均は顔料の環では灰にならない罠——補色を平均すると茶色が出る）。つりあいが取れた和音は中央の円盤が無彩へとけ「イッテンはこれを、調和と呼んだ」／かたむいた和音は勝っている色名を告げる
- **金継ぎ（法則4と5がここで合流）**: 赤紫と紫＝スペクトルに存在しない色（purple line）。**光のスペクトルは線であって環ではなく、目が発明した継ぎ目だけが環をとじている**——その2区画の上に、呼吸する金の継ぎ目を這わせた。シリーズ署名「閉じない円」の色彩版
- **残像のデモ**: 色をタップ→その色が3.5秒灯り、消えると**補色の残像**が浮かぶ（継時対比）。赤紫・紫をタップすると「虹には無い色」の注釈
- **構造の下敷き（法則1・3）**: 一次色の正三角形×二次色の逆三角形＝ダビデの星をうすく内接。一次色は外周に太い印
- **軽い色は浮く**: 花びらの座は明度で少し浮き沈みする（黄は軽く、紫は重い——イッテンの重量感）
- **黄が頂・紫が底**: 軽い色を上に置くイッテンの原則どおりの配置
- **見た目3案**: 地はすべて無彩（色をいちばん立てる画廊の壁）＝玄・煤・鈍色。`?v=A|B|C`・`?p=位相`
- **検証フック**: `window.__iro={setPhase,setChord,get}`
- **配信**: launch.json「ccf5-art」(:4820) の `/12_08/`
