# 十二月 — ひと年に、月は十二・三六八回みちる

## 展示用キャプション

**十二月**
2026年／ジェネラティブアート（インタラクティブ映像）
WebGL2 海霧シェーダ ＋ 2Dキャンバス暦環・実月齢、単一HTML

外の環は暦——睦月から師走まで、人が決めた理想の十二月。
そのなかを、ほんものの月がめぐる。ひと年に、月は12.368回みちる。
朔（新月）のたびに環へ真珠がひとつ置かれ、その列は毎年10.9°ずつとじ残す。
とじ残しが一月ぶんたまると、十三番目の月——閏月が生まれる。
真珠の環がほんとうにとじるのは235朔望月＝十九年後（メトンの環・残り0.087日）。
中心の地球をつつむ水は、月へむかってふくらみ、朔と望に大きく息をする。

## 制作メモ

- **シリーズ**: 「12」— 円環の連作　第四作。企画の正= vault `02_Projects/260822_「12」円環アートシリーズ_企画.md`
- **駆動原理**: 閉じない12.368。主変数は「日」（1970年からの通日）一本。月齢=基準朔（2000-01-06 18:14 UTC）からのmod 29.530589・太陽角=年内通日。**開くと今日のほんものの月齢・月相・潮名**が出る
- **朔の真珠（法則5＝閉じない円）**: 直近61朔望月（約5年）の朔を、その瞬間の太陽角の位置に真珠として置く。連続する朔は29.1°ずつ進み、環は毎年10.9°とじ残す→真珠の列がゆっくり歳差する。**メトンの環**カウンタ（N/235）で19年の大円環を明示
- **例外ノード（法則4）＝閏月**: 同じ暦月の区画にふたつめの朔が落ちたとき、その真珠は「閏」と記される——**状態を持たず計算から自動で現れる**（19年に7回≒章法どおり）
- **月相**: 本物の描画。影の円盤＋照面（右半円＋終端楕円 rx=r·cos(位相)）。照る側は常に太陽をむく（幾何から自動）。月の異名15種（朔・三日月・上弦・十三夜・望・十六夜・立待・居待・寝待・更待・下弦・有明・晦…）を月齢で表示
- **潮**: 旧暦日の型どおり（大潮→中潮→小潮→長潮→若潮→中潮→大潮の15日サイクル）。潮の環は月へむかう双胴のふくらみ（cos2θ）で、朔望（syzygy）に振幅最大＝背景の波も高くなる
- **インタラクション**: ドラッグ一周=ひと朔望月／月名タップ=和風月名の意味／時=止・ゆるり(0.45日/秒)・疾く(40日/秒)の三連ボタン（現在地が点灯）／今日へ
- **中央=大きな月（v1.1赤ペン反映）**: 当初は地球＋潮の膨らみを中央に置いたが「何のオブジェか分からない」→中央を大きな本物の月相に交代。潮は背景の海のうねりと潮名に移した。月の位置は暦の環の上の白い点（朔で太陽と重なり望で対岸へ）
- **疾くの作法（v1.2赤ペン反映）**: 最初は疾くのとき月をフェードで消したが「途中から月が表示されなくなる」→**消さない方式に転換**。見かけの月齢は実際を追いかけ、追いつけない速さでは**歩調を落として約8秒でひと巡り**するタイムラプスになる（rate-limited chase）。追いかけの向きは「時の流れ」に揃える——最短経路だと早送り中に月が逆回りへ反転する罠がある
- **見た目3案**: ページ内切替＝潮騒（海霧の青緑・既定）→月白（銀青の月光）→藍波（藍×金）。`?v=A|B|C`・`?day=通日`
- **踏んだ罠**: 月相パスの ellipse の回転方向フラグ——`b<0` と `b>0` を取り違えると**満月が真っ暗・三日月と十三夜が入れ替わる**。canvasの角度は+yが下＝紙の直感と逆向きなので、朔（面積ゼロ）と望（全円）の両端で必ず実測すること
- **検証フック**: `window.__tsuki={setDay,get}`
