# 十二将 — 天の円盤は、地の方盤の上をすべる

## 展示用キャプション

**十二将**
2026年／ジェネラティブアート（インタラクティブ映像）
WebGL2 灯下シェーダ ＋ 2Dキャンバス式盤（天円地方）、単一HTML

四角い地盤には十二支——動かない大地の座標。
円い天盤には十二天将と北斗七星——めぐる天の座標。
陰陽師の六壬式盤は、月将（太陽のいる宮）をいまの刻にかさねて読む。
ふたつの盤の位相差から、その瞬間の意味が生成される。
太陽の印はつねに今の刻を指し、帝座（真北）に立つ将が今を統べる。
盤は一日にひとめぐり——けれど月将がすすむぶん、毎日およそ1°とじ残す。
この環がとじるのは、一年後。

## 制作メモ

- **シリーズ**: 「12」— 円環の連作　第七作。企画の正= vault `02_Projects/260822_「12」円環アートシリーズ_企画.md`
- **駆動原理**: 天盤×地盤の位相差。シリーズ初の**天円地方**（円い天盤が四角い地盤の上をすべる）。実際の六壬の操作＝**月将（太陽の在る宮の支）を時支（いまの刻）にかさねる**をそのまま実装：天盤の回転角 = (時支−月将)×30°。両方とも実時刻駆動なので、開いた瞬間が本物の課式
- **月将**: 太陽黄経（暦年角−春分77.9°）から宮を求め、白羊=戌将（河魁）から下る十二月将（神后・大吉・功曹・太衝・天罡・太乙・勝光・小吉・伝送・従魁・河魁・登明）。**宮に入った瞬間から次の宮まで同名＝切り上げで取る**（floorだと入宮直後に一つ先へずれる罠）
- **太陽の印**: 天盤の月将の座に灯る金の点。回転の定義により**つねに今の刻（時支）を指す**——盤の仕組みがひと目でわかる
- **帝座**: 真北（頂）に立つ将が「いまを統べる将」＝中央の主役。時支と月将の両方で変わるので、時間と季節の二重リズムで交代する
- **吉凶**: 吉6凶6の二値を色で（吉=金白/凶=朱鈍）。四神（青龍・朱雀・白虎・玄武）は座の点が大きい
- **例外ノード（法則4）＝天空**: 「姿なき霧」＝十二将でただひとり実体を持たない。名は輪郭文字（strokeText）
- **閉じない円（法則5）**: 盤は一日にひとめぐりするが、月将がすすむぶん毎日約1°とじ残す——**環がとじるのは一年後**（説明行は「かさねの文」と交互に9秒で入れ替わるカルーセル）
- **北斗七星**: 天盤の中央で盤とともにまわる（式盤の実物どおり）
- **鬼門**: 地盤の北東角に小さく（第3作の軸とつながる）
- **踏んだ罠**: ①時刻はUTCでなく現地（時支の判定に直結）②中央テキストと天盤下部の将名・太陽印が衝突→天盤を縮め（.56R）テキストを下げ、長文2本は1席交互のカルーセルに ③月将はfloorでなくceil
- **見た目3案**: ページ内切替＝玄式（黒漆×金・既定）→朱盤（朱塗の式盤）→銀墨。`?v=A|B|C`・`?day=`
- **検証フック**: `window.__shou={setDay,get}`
- **配信**: launch.json「ccf5-art」(:4820) の `/12_07/`
