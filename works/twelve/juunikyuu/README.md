# 十二宮 — 春分点は星座をさかのぼる

## 展示用キャプション

**十二宮**
2026年／ジェネラティブアート（インタラクティブ映像）
WebGL2 夜天シェーダ ＋ 2Dキャンバス二重円環、単一HTML

内の環は季節（春分・夏至・秋分・冬至）——人の暦。
外の環は星座——星の暦。ふたつの環は、実は少しずつずれてゆく。
地球の首振り（歳差）が春分点を71.6年に1°ずつ後退させ、
2,150年ごとに「時代」の星座が入れ替わる。いまは双魚宮の時代の終わり。
環をまわせば千年が過ぎ、遠くまで行けば星座の形そのものが溶けてゆく——
星にも固有の速度があり、25,772年めぐっても、同じ空は二度と戻らない。

## 制作メモ

- **シリーズ**: 「12」— 円環の連作　第二作。企画の正= vault `02_Projects/260822_「12」円環アートシリーズ_企画.md`
- **駆動原理**: 歳差。主変数は「年」ただひとつ（epoch）。アヤナムシャ=23.85°+(年-2000)×50.29″で星の環の回転角が決まり、春分点（画面真上・固定）の下にある宮が「時代」になる。中央のカウントダウン（あと約N年で◯◯宮の時代）は歳差率からの厳密値
- **閉じない円（法則5）**: 固有運動。各恒星に速度ベクトルを持たせ、一周(25,772年)で経度±7°・径±35%まで流れる＝環を一周しても星座の形は元に戻らない。遠い時代へ行くほど見慣れた形が溶ける
- **例外ノード（法則4）**: 蛇遣（へびつかい）＝十三番目。蠍と射手のあいだに気配だけ（呼吸する微光）で常在し、タップで12秒だけ姿を見せる。太陽の道が実際に通る13番目の星座
- **法則3**: 火地風水の正三角形×4を環に内接（時代の宮の元素だけ明るい）。目盛は36デーカン（12宮×10°＝古代エジプトの分節）
- **インタラクション**: ドラッグ=環を回す＝時間旅行（30°=2,150年）／ホイール=年送り／星座タップ=見つめる（中央に詳細10秒）／時=止・ゆるり(60年/秒)・疾く(1,600年/秒)／今日へ／空白=停止
- **見た目3案**: ページ内切替＝星夜（藍黒×金・既定）→蒼穹（青×元素鮮やか）→古図（羊皮紙×朱＝古星図）。初期指定は `?v=A|B|C`・`?epoch=年` で開始年も指定可
- **踏んだ罠**: ①星座グリフ（♈♓等）は素のserifだとemoji表示になる→VS15(U+FE0E)を後置して文字として描く ②宮名ラベルは環の約1.5倍まで伸びる→半径は `min(W*.315, H*.36)`（縦長画面で左右にはみ出す）
- **v2 本気モード（8/22赤ペン反映）＝解説の間**: 宮をタップで開くカード。①**Urania's Mirror（1825年・Sidney Hall画）の手彩色星座カード13枚**（十二宮＋蛇遣=Serpentarius）をWikimedia Commonsからリサーチして設置（すべてパブリックドメイン・contain表示でカード全体・出典スクリム常時表示・`img/`同名上書きで差し替え可）②ギリシア神話の物語を書き下ろし（金羊毛・エウロパ・ネメアの獅子=第一功業とのシリーズ縁・オリオンと蠍・ケイロン・山羊魚・ガニュメデス…）③**「春分点がこの宮にあった時代」を歳差から実計算**（この環の暦法＝Lahiri整合。白羊宮=紀元前1860ごろ〜西暦290ごろ、双魚宮=〜西暦2440ごろ、天蝎宮=西暦8880〜11030ごろ等。2000年に最も近い周期窓を選ぶ）④蛇遣タップは顕現＋カードの二段構え。パネルはavailベースの文字サイズ（第10作の掟）
