# 十二経 — 気はひと日に、からだを三たびめぐる

## 展示用キャプション

**十二経**
2026年／ジェネラティブアート（インタラクティブ映像）
WebGL2 気霧シェーダ ＋ 2Dキャンバス二十四時間盤・銅人、単一HTML

外は二十四時間の盤——子午流注。気の峰が二時間ごとにひとつの経をめぐり、
峰の対岸ではかならず、ひとつの経が谷に沈む（十二時間後のシーソー）。
中心には銅人が立つ。気の光は「胸から手へ、手から頭へ、頭から足へ、足から胸へ」
——四拍子の道を、ひと日に三たびめぐって環をとじる（4×3＝12）。
三焦だけは輪郭の文字で書かれる。名あって形なし——実の臓器を持たない、ただひとつの腑。
からだの奥には、ふたつの波。体の12.0時間と、七億年前の海の記憶12.4時間。
ふたつの波は、十五日半にいちどしか、めぐり会わない。

## 制作メモ

- **シリーズ**: 「12」— 円環の連作　第五作。企画の正= vault `02_Projects/260822_「12」円環アートシリーズ_企画.md`
- **駆動原理**: 子午流注＝24時間の体。主変数は「時」一本。開くと**ほんものの現在時刻**の経が峰にいる。盤は子=真上（十二支の盤と同じ向き・子卯午酉の刻名つき）
- **4×3の構造（法則1）**: 流注の4拍子（胸→手／手→頭／頭→足／足→胸）が3周して12経＝銅人の上を気の光が実際になぞる。めぐりごとに左右の側を替える
- **対極シーソー（法則2）**: 各経の明るさ＝峰からの角距離のコサイン。峰がめぐると谷も対岸をめぐる——経名の明暗そのものが波になる
- **表裏の橋**: 同じ五行の隣り合う2経（肺大腸・胃脾・心小腸・膀胱腎・心包三焦・胆肝）を小さな弧で結ぶ。陰陽は内外の点で示す
- **例外ノード（法則4）＝三焦**: 「名あって形なし」。弧は破線・名は fillText でなく **strokeText（輪郭のみ）** で描く——形のなさをタイポグラフィで実装。タップで注釈
- **閉じない円（法則5）＝うなり**: 体内の12.0時間リズム（概日の第二倍音）と、潮汐リズム12.4時間（体に残る太古の海の記憶＝circatidal）。ふたつの波の環がゆっくり位相をずらし、**372時間＝15.5日にいちど**だけ重なる。中央に「つぎのめぐり会いまで N日」
- **見かけの刻**: 疾く(3時間/秒)では体の光が2.7秒で一巡してしまう→**rate-limited chase**（一日＝最短12秒）で歩調を落として追いかける（第4作で確立した掟）
- **インタラクション**: ドラッグ一周=一日／経をタップ=詳細（乱れたときの感情も）／止・ゆるり(15分/秒)・疾く(3時間/秒)／いまへ
- **見た目3案**: ページ内切替＝銅人（漆×金・既定）→水墨→五行（五行色鮮やか）。`?v=A|B|C`・`?hour=`
- **踏んだ罠**: タップ→経の変換で「中心時刻へ+1補正」を入れたら1経ずれた。activeIdx()は生の時刻を渡すのが正
- **踏んだ罠（人体が裂けた）**: 輪郭点列の先頭 `[0,-1.0]` に**×Bのスケールを掛け忘れ**、頭頂が体の中心（原点の1px上）に落ちて「頭から胴を裂く楔」ができた。デバッグ手順が有効だった：①輪郭だけの大きなテストページを作る ②スムージングを外し素の折れ線で塗る（曲線の問題か点データの問題か切り分け）③右半身とミラー側を色分けして描く＋minX/maxXを画面に出す——③で「片方の端点だけ原点付近」が見えて一発特定。**シルエットの点列は必ず素の折れ線で一度検分する**
- **銅人v1.1→v1.2（赤ペン反映「棒人間がしょぼい」→「まだしょぼい」）**: 最終形＝**頭からつま先まで一筆の閉スプライン（80点・8頭身）のシルエット**。パーツ組み（fillLimb）は継ぎ目と塊感が消えず廃止。①輪郭点列RSIDEを右半身だけ定義し左右ミラーで閉じる（脇と脚の間の「抜け」は輪郭自身が作る）②**一枚のオフスクリーンに焼いてから合成**（パーツごとにshadowBlurを掛けると内側でグローが濁る）③陰影=source-atop縦グラデ＋**縁の内側に太い暗ストローク**（丸み）＋輪郭リムライト1px（下端を濃くしすぎると脚が背景に溶ける——0.16まで）④経穴の星座（25点が瞬く）＋丹田の内灯
- **舞台v1.2（赤ペン反映「アートとしての美しさとわかりやすさ」）**: ①背景を漆黒に刷新し**一条の光**（天からのシャフト＋床のうけひかり）で像を照らす＝美術館の照明 ②光塵2層 ③気は単点でなく**26粒の川**（コメット・ゆらぎつき）④**背後に臓の大きな字**（気配の刷り）⑤**盤から体への糸**（いまの経の座→道のはじまり・流れる破線）⑥環のいまの弧も流れる破線 ⑦うなりの二波は**めぐり会い（位相差<0.5rad）で金にとけて輝く** ⑧ことば再設計＝ながれ「胸 → 手」明示・「谷にしずむのは◯」明示・波の凡例に色玉
