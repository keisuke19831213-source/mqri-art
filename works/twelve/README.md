# 結 — おなじ場所、一段ふかく

## 展示用キャプション

**結**
2026年／ジェネラティブアート（インタラクティブ映像）
WebGL2 王冠シェーダ ＋ 2Dキャンバス環と螺旋、単一HTML

環の十二の席にすわっているのは、この連作の十二の作品そのもの。
十二番目の席には「結」——この作品自身がすわっている。環は、じぶんを含んでとじる。
めぐる光が席をわたるたび、その作品の音が鳴る——連作はひとつの半音階だった。
ドの十二律にはじまり、シの結で「もう戻れない」ところまでのぼり、
そして十三番目——高いド。中央の螺旋の頂、一番目の真珠の真上で金にひかる。
環は閉じない、と十二回いいつづけてきたこの連作の、これが結び：
閉じないのではない。おなじ場所に、一段ふかく、還ってくるのだ。

## 制作メモ

- **シリーズ**: 「12」— 円環の連作　**第十二作・結**（これでラインナップ0+12+1が完結：母型sekki-circle＝0、十二作、そして本作の内にある十三番目＝高いド）
- **駆動原理**: 自己言及の環。十二の席=十二の作品（結自身が十二席目＝ウロボロス）。めぐる光が各席で**その作品の音**を鳴らす（C=十二律〜B=結の半音階・WebAudioは第一作とおなじ灯し方＝ブックエンド）
- **音と動詞の対応**: 本人の「12音の神秘」メモ（Cosmic Affective Mandala）の12動詞をそのまま各作品に——在る=律・歪む=宮・動く=支・感じる=月・観る=経・**止まる=縁（断ち切りの門）**・浮く=将・意志=色・溶ける=月精・**沈む=夜叉（煩悩をしずめる）**・拡がる=感・欲する=結。不思議なほど作品の性格と合う
- **中央の螺旋**: 一巻きのぼる螺旋に13の真珠（各作品の色）。**十三番目は一番目の真上**＝オクターブ。点線の縦糸がふたつを結ぶ。高いドの瞬間、空が金にひらき「Nめぐりめ——十二の環を、もういちど」
- **入口の機能（Home哲学＝入口はひとつ）**: 席をタップ=見つめる（駆動原理と例外の席を表示）→**もういちどタップでその作品へ跳ぶ**（相対パス../12_0N/）。この作品が連作全体の玄関を兼ねる
- **例外ノード（法則4）**: 十三番目の真珠そのもの（十二の外にある帰還の席）。また十二色の席だけは色相をめぐりつづける
- **閉じない円（法則5）＝連作の結論**: 「閉じないのではない。おなじ場所に、一段ふかく還ってくる」——螺旋
- **見た目3案**: 王冠（夜×金・既定）→原初（Cの海＝第一作の象徴へのブックエンド）→白金。`?v=A|B|C`・`?p=位相`
- **検証フック**: `window.__musubi={set,get}`
