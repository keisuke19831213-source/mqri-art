# 十二夜叉 — まもりは二時間ごとに、うけつがれる

## 展示用キャプション

**十二夜叉**
2026年／ジェネラティブアート（インタラクティブ映像）
WebGL2 瑠璃光シェーダ ＋ 2Dキャンバス守護の環、単一HTML

中心に、薬師瑠璃光——日光と月光をしたがえた、まもられるべき光。
そのまわりを、十二の夜叉の将が十二支の座からまもっている。
まもりは二時間ごとの交代。いまの刻の将が当番に立ち、
七千の眷属が金の陣となって持ち場をめぐる——十二将で八万四千、人の煩悩とおなじ数。
外の闇からは煩悩の黒い粒がたえず漂いより、結界にふれて金の閃きにしずむ。
ひとつしずめても、煩悩は尽きない。だからこの環は閉じずに、まもりは明日へつづく。
真達羅だけが、武器を持たない。

## 制作メモ

- **シリーズ**: 「12」— 円環の連作　第十作。企画の正= vault `02_Projects/260822_「12」円環アートシリーズ_企画.md`
- **駆動原理**: 二時間交代の守護シフト（十二神将と十二支の習合＝24時間の警護網）。**実時刻で開き、いまの刻の将が当番**。盤の向きは十二支の作と同じ（子=真北）
- **七千の眷属**: 当番の持ち場に110粒の金の陣（7000の見立て・ガウス状の散らばり×ゆらぎ×瞬き）。**刻がかわると陣が環に沿って次の持ち場へ行進する**（rate-limited chase＝掟）。ひかえの将にも小さな灯が3つずつ
- **煩悩の調伏（物理が守りを見せる）**: 黒い粒が外縁からたえず漂いより、結界（当番側があつい膜）にふれると金の輪の閃きでしずむ。**しずめた数のカウンタは尽きない＝閉じない円（法則5）**——「だから環は閉じずに、まもりは明日へつづく」
- **例外ノード（法則4）＝真達羅**: 十二将でただひとり武器を持たない素手の将。名は輪郭文字（strokeText）
- **新様の意匠**: 各将の頭上に十二支の字がちょこんと乗る（新様＝頭上に動物が乗る様式の翻訳）
- **総大将**: 一年交代の伝承——2026年＝丙午なので**因達羅**（午）に小さな冠。中央のことばにも注記
- **中心**: 薬師瑠璃光の珠（脈動する瑠璃のグラデ）＋日光菩薩（金）・月光菩薩（銀白）が扁平軌道で両脇をめぐる
- **持物・本地仏**: 一説と明記（伝によって入れかわるため）。宮毘羅=太刀/弥勒、伐折羅=宝剣/勢至、…毘羯羅=三鈷杵/釈迦
- **踏んだ罠**: strict modeでは未宣言変数への代入（カンマ式のなかの `hash=`）が即死する——ハッシュ計算は変数宣言してから
- **v1.1 本気モード改修（赤ペン反映）**: ①字かぶり解消＝支の字を環の内がわへ・方位も内側へ・盤をひとまわり小さく（R=min(W*.30,H*.34)）②真達羅の輪郭文字をやめる（不良に見える）——素手の物語は解説の間で語る ③**解説の間**新設＝将をタップで開くカード：**梵名**（クンビーラ・ヴァジュラ・インドラ・キンナラ…）・支と刻・**持物の線画12種**（太刀/宝剣/独鈷/宝珠/矢/法螺貝/鉾/弓矢/斧/掌/槌/三鈷杵を手描きパス）・本地仏・解説文（金毘羅と同源／新薬師寺の伐折羅は切手の顔／インドラ=帝釈天／緊那羅だから素手…）④**像の写真の差し込み口**＝`img/01_kubira.jpg`〜`12_bikara.jpg` を置くと解説の間に自動で入る（cover表示・無いときは支の透かし＋持物の線画＋案内文）
- **踏んだ罠（金のドーナツ事件）**: 結界の明るさ計算で `d=Math.min(d,TAU-d)` が |off|>2π のとき**負**になり、s が巨大化して lineWidth≈100 の金の環が画面を覆った。**角度差は atan2(sin,cos) で -π..π にたたみ、係数は必ず 0..1 にクランプ**（hostAも毎フレームたたむ）。切り分けは①2Dキャンバス非表示でGL/2D判定 ②ブロック単位で if(false) 化の二段が速い
- **見た目3案**: 瑠璃（藍夜×金・既定）→護摩（火の堂）→月白。`?v=A|B|C`・`?hour=`
- **検証フック**: `window.__yasha={setHour,get}`
- **配信**: launch.json「ccf5-art」(:4820) の `/12_10/`

- **v1.3（赤ペン反映「写真が微妙にしか見えない」）**: 立像は縦長なのに横長窓のcoverで胴だけ切り出していた→**contain（像はぜったいに切らない）**へ転換。横画面=左右二段組（左に全身・右にことば）／縦画面=縦積みの大窓。像の背に台座のほのあかり（radialGradient）。**ことばの基準サイズは「使える高さ」から算出**（avail*1.45とtw*2.4でクランプ）——固定比率だと小さい窓であふれる
