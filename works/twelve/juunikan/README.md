# 十二感 — からだは、環に巻きついている

## 展示用キャプション

**十二感**
2026年／ジェネラティブアート（インタラクティブ映像）
WebGL2 気層シェーダ ＋ 2Dキャンバス感覚の環と人体、単一HTML

シュタイナーは、感覚は五つではなく十二あると考えた。
そして十二の感覚を黄道十二宮にかさね、頭から足へ、からだの部位にすまわせた。
だからこの環では、頭（自我感覚・白羊宮）からはじまり足（味覚・双魚宮）でとじる——
からだが、環に巻きついている。
下位の感覚（触覚・生命・運動・平衡）は、環のちょうど対岸の上位の感覚へ育つ。
四つの鏡像対は、四本の直径。じぶんの輪郭を知った者だけが、他者の輪郭を尊べる。
熱感覚だけは対をもたない——関心そのものだから、心臓に住む。
そして、つかわない感覚はしずかに眠る。環はひとりでにはとじない。

## 制作メモ

- **シリーズ**: 「12」— 円環の連作　第十一作。企画の正= vault `02_Projects/260822_「12」円環アートシリーズ_企画.md`
- **駆動原理**: 円環＝人体。十二感覚を黄道順（＝頭→足の身体部位順）に配し、環の各感覚から中央の人体の部位へ**十二本の糸**を張る。中央の人体は第五作の一筆シルエットを再登板（掟＝素の折れ線で検分済みの点列・オフスクリーン焼き）
- **鏡像対＝四本の直径（構造の奇跡）**: 触覚(天秤)↔自我感覚(白羊)・生命(天蝎)↔思考(金牛)・運動(人馬)↔言語(双児)・平衡(磨羯)↔聴覚(巨蟹)——黄道順に置くと4対が**ちょうど直径**になる。観想がその対に来ると直径が流れる破線になり、**変容の粒が下から上へのぼる**（下位の感覚が上位へ育つメタモルフォーゼ）
- **三期の弧**: 下位=意志（0〜7歳）・中位=感情（7〜14歳）・上位=思考（14〜21歳）を層色で（下位=土の赤褐・中位=金・上位=空色）。**背景そのものが「下は土、上は光」の縦グラデ**＝作品の主張を地にした
- **例外ノード（法則4）＝熱感覚**: 唯一対をもたない中位の感覚。「関心そのもの」だから**心臓に住み、熾のように常にあたたかく脈打つ**
- **閉じない円（法則5）＝手入れの環**: 観想されていない感覚のともしびはゆっくり眠る（下限0.3）。タップでともし直す。「いちばん眠っている感覚——◯◯。ふれて、ともし直す」の案内。**環はひとりでにはとじない**
- **ことば**: 観想の焦点＝感覚名・読み・宮・すみか（部位）・層と発達期・ひとこと・鏡像対の文（4本書き下ろし）
- **見た目3案**: 気層（土と空・既定）→墨→燈。`?v=A|B|C`・`?p=位相`
- **検証フック**: `window.__kan={set,get}`
- **配信**: launch.json「ccf5-art」(:4820) の `/12_11/`
