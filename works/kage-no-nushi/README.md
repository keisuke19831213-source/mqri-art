# 影の主 — Kage no Nushi（2026-09-04・ccf5 art）

メタトロンキューブ（フルーツ・オブ・ライフ13円＋全対78線）は**影**である。三回対称軸に沿った正射影として、その影に**厳密に住む立体**は立方体・正八面体・星型八面体（二つの正四面体）だけ。正二十面体は外の六角形の半径が 4 でなく 2φ＝3.236（内環2との比 1:φ）のときに初めて住み、正十二面体は「六の環（2）と十二の環（2√2）」を要る。本作は13の円を滑らせて比を変え、影から主を立ち上がらせる。立体は影の糸（頂点から真下へ）で平面の点に結ばれ、立ち上がった主の影の線だけが主の色で灯る。

- ローカル：launch.json「ccf5-art」→ http://localhost:4820/art_kage/
- URL：`?scene=1..6`（1立方 2八面 3星型八面体 4二十面 5十二面 6三つ）`?pal=0..2`（夜・墨・藍）`?warm=秒` `?yaw= ?pitch= ?zoom=`

## 検算（コンソール「影の環」に出る）
- 立方体（半辺1）を (1,1,1) 軸で射影：2頂点→中心、6頂点→半径 √(8/3)=1.633。正八面体（頂点 (±1,0,0)）→半径 √(2/3)=0.816。**比 1:2・角度は60°の倍数でそろう**＝古典のメタトロン（内環2・外環4）。
- 正四面体は立方体の4頂点＝頂点1つが中心、3つが外環。二つで星。
- 正二十面体 (0,±1,±φ)：面の三角形6頂点→半径 1.155s、残り6→1.868s。**比 1/φ**。内環2に合わせると外環 2φ。
- 正十二面体：2頂点→中心、6→1.155s'、12→1.633s'。**比 1/√2**。内環2に合わせると外環 2√2。
- 平面内の回転は「外環の点が 0°,60°,… に乗る」角を走査で決める（alignRot）。

## 描き方
- 平面は全画面のレイ・平面交差で2D SDF（13円・78線・影の線）。深度も書く。
- 辺はインスタンス化した板（画面に正対する幅・カプセル風の陰影）、頂点は球のインポスタ。深度バッファで平面との前後を正しく。
- 明るい彩（墨）は加算合成だと線が白飛びする→乗算済みアルファ（ONE, ONE_MINUS_SRC_ALPHA）に統一し、線は暗い色・影の線は「引く」（負の輝き）。
- 持ち上げは軸方向なので射影は不変＝影が動かない。だから糸がまっすぐ立つ。

## 学び
- 「メタトロンキューブに五つのプラトン立体が全部ある」は半分だけ本当。二十・十二は比が違う。図で嘘をつかず、比を変える動きそのものを作品にした。

## v2（同日）全角度と真俯瞰の吸い付き
- 視点は全角度（真下からも）。上か下へ倒し切る（|pitch|>75°）と ±90° へ吸い付き、同時に**望遠→正射影へドリーズーム**（画角30°→0.32°・対象面での半高さを保って距離を伸ばす）。遠近法のままだと持ち上げた立体は影より大きく見えるので、正射影に寄せて初めて辺が影と**ぴたり**重なる。一致すると影の線が明るくなり、右上に「真俯瞰 — 辺は影と一致（正射影）」。
- 下から見るときは平面を硝子扱い（深度を最遠に書く）にして立体を隠さない。
- 自動巡回は方位を回しながら高さを sin で上下し、上がり切ると吸い付く時間が来る。V／「俯瞰」で即座に。
- 罠：真上でカメラの right ベクトルを forward から作ると 0 になって NaN。yaw から直接 (−sin, cos, 0) で作る。FAR は距離に応じて伸ばす（正射影時は距離が数百になる）。

## v3（9/5）マカバの修正と登場・退場
- 星型八面体（マカバ）は二つの正四面体で一体。持ち上げを立体ごとに計算したら二つの高さが違って形が壊れた → 二つは同じ高さ（大きい方）に置く。
- 登場＝影から膨らむ：頂点 z' = p·(z + 持ち上げ) で p=0 は影そのもの（辺が影の線に重なる）、p=1 で主。easeOutBack（少し行き過ぎて戻る）1.9秒。辺の明るさは p/0.35 で立ち上がるので、寝ている間は影の線が担う。
- 退場＝影へしぼむ：easeInCubic 0.9秒で p→0、その後 sA が2.5/sで消える。影の線は出入りの瞬間ほど強く灯る。
- 順番＝退場 → 環が滑る（1.3秒・必要な場面だけ）→ 登場。同じ立体が次の場面にも居るなら退場させない。
- 検証URL：`?scene=N&warm=秒`（登場途中）`?from=M&scene=N&warm=秒`（退場途中）。
- v3b：同じ場面の主は**同じ高さ（共通の中心）**に置く（groupLift）。立方体（半辺s）と正八面体（頂点 (±s,0,0)）は同じ s=2.449 なので、正八面体は立方体の面の中心に内接し、星型八面体は立方体の頂点を共有する。居残る主は新しい高さへ 2.2/s で滑る。登場は 0.45 秒ずつずらす（立方体→正八面体→星型八面体）。
- 罠：ANIM の初期化で LIFT_H を先に参照して TDZ エラー（真っ黒）。定義順に注意。
