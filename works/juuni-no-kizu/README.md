# 十二の疵 — Jūni no Kizu（2026-09-05・ccf5 art）

球に生命の花を咲かせると、十二の五弁が必ず残る。その疵に金を流す（金継ぎ）。4月8日の「球の生命の花」（flower-of-life-geodesic / sphere-of-life-sdf）の作り直し。

## 数学の事実
- 六方格子（生命の花の円の中心）は球面に載らない。オイラーの公式 V−E+F=2 から、六角形と五角形だけの球面分割では五角形が**ちょうど12個**（分割をいくら細かくしても）。
- ここでは正二十面体の測地線分割（class I・分割数ν）の頂点 10ν²+2 個を円の中心にし、各円の半径＝隣への角距離の平均で球面の小円を描く。五弁（次数5）は正二十面体の12頂点。右上に V−E+F の実数を出す。
- 球面では隣への距離が一様でないので、円は完全には合わない（わずかな歪みは本物）。

## 描き方
- 場（線までの角距離・覆う円の数・疵までの角距離・最寄り中心までの角距離）をキューブマップ（1024²×6・RGBA16F）に一度焼く。頂点はRGBA32Fの1行テクスチャで渡し、|dot−cos r|<0.12 の円だけ acos を計算。分割を変えた時だけ焼き直す（6面を1フレーム1面）。
- 球は解析交差。線は場の勾配で法線を傾けた溝、釉は覆う円の数で薄く濃淡、溝に溜まって濃くなる。
- 疵：疵の円の内側で隣の円にも覆われる所を金（箔のむら・線は溝として残る）。K で金を隠す（隠しても中心に小さな金の点）。
- 彩3：青磁（呉須でなく淡い溝）／黒漆（金の線・疵は朱）／白磁（染付の線）。

## 学び・罠
- 「五枚の花びらだけ金」（覆う数がちょうど2）にすると金がほぼ消える。花の中では円の内側はほぼ三重に覆われる。円全体を金にして溝で五芒を残す方が読める。
- 姿勢はシェーダに逆行列（方向→場の座標）で渡す。R=Rx·Rz を列優先で読ませると転置＝逆になる。
- ブラウザペインの配信サーバが落ちると preview_start が「5台上限」で立てられない → 素の python http.server で代用。
