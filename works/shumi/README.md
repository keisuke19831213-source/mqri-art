# 須弥 — Shumi（2026-09-04・ccf5 art）

Śrī Yantra の九つの三角形を、Chiodo「On the construction of the Śrī Yantra」（C. R. Math. 359, 2021）の並行条件で**厳密に解き**（ニュートン法・残差 1e-16）、重なりの数＝九層の高さを紙に浮き彫りにする。以前の作（2026-03-26・p5）は正三角形を大きさ違いに重ねただけで、交わるべき19組のうち一致するのは2組だった。`X` で往復して比べられる。

- ローカル：launch.json「ccf5-art」→ http://localhost:4820/art_shumi/
- URL：`?warm=30`（完成状態）`?old=1`（以前の作図）`?still=1`（呼吸なし）`?zoom=1.6`

## 条件（Chiodo 2021 §1）
- t1..t9 は底辺の高さ順（上から）。i≤5 は下向き・i≥6 は上向き。各三角形＝(頂点の高さ a, 底辺の高さ b, 半幅 w)。
- (i) t3 と t7 は同じ外接円（＝単位円に内接：a=∓1・底辺の端が円上）
- (ii) 頂点＝別の三角形の底辺の中点：(t8,t1)(t6,t2)(t9,t3)(t1,t6)(t5,t7)(t4,t8)(t2,t9) → 7式
- (iii) 下向き t' の脚・上向き t''' の脚・t'' の底辺が一点で交わる：(1,2,7)(2,3,7)(1,3,8)(1,4,6)(1,5,9)(4,6,9)(2,7,9)(3,7,8)(3,8,9)(4,4,8)(5,5,6)(2,6,6) → 12式（脚が y=b'' を切る x が等しい）
- 未知数 27 − (i)で固定 6 − 底辺4つ = 19 未知数・19 式。**四つの自由度＝ t3, t6, t7, t9 の底辺の高さ**。伝統（Kaivalyāśrama）の直径48分割の 17, 27, 30, 42 を既定に置き、残りを解く。
- 初期値は texample.net の並行配置（1組だけ 1.3e-3 ずれていた）。ニュートン3〜4回で 1e-16。

## 見え
- 重なりの数（0〜9）で顔料の色を分け、その数を高さとして紙の浮き彫りにする（須弥山＝メール。立体のシュリヤントラ Sri Meru の読み）。
- 交わるべき19組（右側12＋軸7）は毎フレーム「二つの交点」として計算し、重なれば金の点、離れていれば朱の二点と線＝ずれそのものが見える。
- 呼吸：四つの底辺を Lissajous（41/59/73/97秒）で揺らし、毎フレーム解き直す。妥当性（順序・向き・幅）が壊れる解は捨てて前の解を保つ。

## 罠・学び
- 正三角形の重ね置きは「それらしい」が交点が合わない。本物は条件で決まる族（自由度4）で、ひとつの図ではない。
- 面の数は 56（三角形以外の面もある）。「43の三角形」は三角形だけを数えた伝統の数え方。
- 交点の対は「一致したら金」の判定を 0.5px で切る。世界座標で半径を持たせないと高解像で点が消える。

## v2（同日）触れる・彩・形
- **彩**（1〜5・画面の「彩」）＝伝統／夜／水／朱／翠。顔料10色＋墨＋紙＋花弁＋方形を組で持ち、1.6/s で補間。「巡」（C）は24秒ごとに次の彩へ。暗い彩は body.dark で文字色も切り替える。
- **須弥山**（M・「山」）＝重なりの数の浮き彫りを強くし（k 0.055→0.275）、影の深い陰影式に切り替える。Shift＋ドラッグで光の方位と高さ。
- **散策**（R・「散策」）＝四つの底辺を Ornstein–Uhlenbeck で歩く（毎フレーム解き直し、妥当性が壊れる解は捨てる）。T で伝統に戻す。軸上の四つの輪は指が近づくと現れ、ドラッグ中は金。
- **急所を叩く**＝最寄りの金の点から光の環が線の上だけを走り（lineMask）、通過する金の点で火花。二重タップ＝以前の作図と往復。
- **三角に触れる**＝縁に最も近い三角形（0.035以内）の縁が金に浮かび、その面がわずかに明るむ。
- 検証パラメータ：`?pal=n` `?mt=1` `?pulse=0.45` `?ptr=x,y` `?zoom=`。
- 罠：ブラウザペインが隠れていると rAF が止まり、彩の補間が途中で凍った絵が撮れる（灰色の紙）。起動時の彩は snap で即時に合わせ、warm は64フレーム回す。
