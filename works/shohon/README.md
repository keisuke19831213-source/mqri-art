# 正本 — Shōhon（2026-09-04・ccf5 art）

生命の花の**正本**（`reference/flower-of-life.svg`）を光学ガラスの円盤に浮き彫りにし、太陽光の屈折コースティクスと煌めきをパストレースで「読む」作品。単一 `index.html`（WebGL2）で自己完結。正本のSVGはそのまま同梱（`<script id="shohon">`）し、`R` キーで浮き彫りの上に赤く重ねて照合できる。

- ローカル：launch.json「ccf5-art」→ http://localhost:4820/art_shohon/
- 検証用URL：`?warm=40`（作品時間40秒＝視線と太陽が揃う瞬間）`?sun=仰角,方位` `?pitch= ?yaw= ?zoom=` `?ref=1`（正本重ね）`?dbg=map`（コースティクス写像：白＝＋／青＝−）`?probe=1`（写像中央の数値と描画時間）`?mask=1|2`（＋のみ／−のみ）`?D= ?w= ?rough= ?disp= ?exp= ?map= ?ph=`

## 正本の幾何（SVGから数値で確定・残差0.0026）

- 単位＝円の半径（SVGでは 68.03px）。中心 (238.62, 238.62)。格子は六方格子・基底 (0,1),(√3/2,1/2)。
- |c| ≤ 2 の**19円は全円**。|c| = √7, 3, 2√3, √13 の**36円は「19円の和集合の内側」にある弧だけ**（span はそれぞれ 180°・120°・60°・60°）。|c|=4 の円は和集合に一点で接するだけで描かれない。
- 環は r=3.0（=204.09/68.03）と r=3.4855（=237.12/68.03＝viewBox の縁−線幅/2）。
- 合計57要素（`ELEMENTS` 表：cx, cy, 開始角, span, 半径, 環番号）。外側の弧は JS で「和集合の内側」を走査して開始角と span を焼いてあるので、シェーダは円弧SDF 57本の min だけで済む。

## 光学（物理が演出を書く）

- **線の断面は放物線の凸**（浮き彫り）。溝（凹）は凹レンズで光を散らし床に暗線しか結ばない。凸なら円柱レンズになり、床に光の線を結ぶ。
- **像側焦点 f' = n·ρ/(n−1)** を床までの厚み T=0.32 に合わせる（ρ = w²/2D = 0.109）。最初 f=ρ/(n−1) と n を落として焦点が床の奥（0.47）にあり、線が絞れなかった（写像の＋の広がりで気づいた）。
- **視線と太陽が揃うと線が燃える**：床に結んだ光の線が同じレンズ越しに眼へ戻る（再帰反射の条件）。ただし円柱レンズは斜入射で焦点が崩れるので、揃う方向は 60° 以上の高さが要る。既定の視点を 60° にし、太陽は視線を中心にした8の字（120秒ごとに揃う）。
- 太陽が視線から外れた時は Beckmann（σ=0.03）の解析ハイライトで線が銀に光る。確率で法線を揺らす方式は「蛍」（白い点）を撒くので、カメラ側は解析に置き換えた（フォトン側は揺らしたままで良い）。
- 分散は R/G/B で n±0.02（フリント寄りに強調）。揃った瞬間の金と藍はこれ。

## 差分フォトン写像（ノイズを線の中だけに閉じ込める）

- 床の照度 = **解析の平板モデル E_flat** ＋ **写像 Δ**。フォトンは「真の着地に＋、平板モデルの着地に−」の2頂点で撒く（同じ乱数種）。平らな所では＋と−が同じ座標に落ちて厳密に相殺し、線の帯の中だけに信号が残る。
- 上面の交差は平面解析＋ニュートン3回。溝の無い場所では平面の式と同じ算術に戻るので相殺がビット単位に近い（球面追跡だと 1e-4 のズレが 2% のノイズになる）。
- 撒く場所は線の帯（半幅 w）だけ。要素は弧長で重み付けして選び、pdf は帯に重なる本数 cnt で補正（交点で二重に数えない）。縁は別枠で環状に撒く（丸い縁で屈折した光と、平らな円柱モデルの影の差）。
- 写像 2048²・カーネル σ=0.6texel・EMA（太陽が動く時 K=40、静止時 900）。`?probe=1` で「＋の総量 ≒ −の総量」（エネルギー保存）と「＋の最大/−の最小」（集光度）を数字で見る。揃った瞬間で集光度 ≈ 3.8〜4.3倍。

## 罠

- 1画素ごとに色チャンネルを抽選して×3で戻す方式は、収束が遅く画面全体が粒子だらけに見える。分散が要るのは写像側だけなので、カメラ側は分散なし（吸収だけ vec3）にした。
- 環境（空）を明るくすると硝子が乳白に見える（反射が透過と同じ明るさになる）。暗い室内の天窓＋一つの太陽にすると硝子が硝子に見える。
- 床の値ノイズを大きなスケールで振ると迷彩柄になる。石は「ほぼ一様＋細かい粒＋薄い層」で。
- ブラウザペインでは `zoom` 領域切り抜きが未対応＝全画面スクショが返る。細部は `?zoom=2.6` で寄って撮る。
