# 検卵 — Kenran

ccf5-art シリーズ／テーマ「卵」（2026-08-29）
単一 index.html・WebGL2・自己完結。配信は `/art_kenran/`（ポート4820・launch.json「ccf5-art」）。

## コンセプト

検卵（けんらん）＝卵に光を透かして命を検める養鶏の技法。読みが「絢爛」と重なる。
光源は外のランプではなく **卵の中の命そのもの** — 内から灯る光を、殻越しに視る。
約104秒でひとつの一生が循環する：微光 → 鼓動 → 血管網の成長 → ひび → 孵化の金 → 静寂。

## 手わざ（インタラクション）— 卵にする所作をそのまま操作に

- **かざす（長押し260ms〜）**: 指の下に検卵ライトの珠が灯り、殻を透かして中を照らす——血管が影絵として浮かぶ。そのまま滑らせると光を検分に動かせる。**かざしている間は温もりで命が3倍速で育つ**（孵卵器の温度）。
- **つつく（タップ）**: ノック。中の命が蹴り返す（胚の近くで光の一撃＋卵が揺れる＋心拍が2秒速まる）。**ひび割れ期はノックのたびひびが進み（+0.05, 上限0.30）、終盤(ph0.84–0.92)は1タップ=+1秒で孵化を手伝える**。
- **なでる（すぐ動かす）**: まわす（オービット）。
- **ホイール / ピンチ**: 近づく（dist 2.4–5.2）。

実装の勘所:
- タップ/長押し/ドラッグの判別は「260msタイマー＋移動7px閾値」の状態機械（idle/maybe/orbit/lamp/pinch）。長押し成立後の移動はカメラでなくライトに割り当てる（かざしたまま検分、が自然)。
- ライトの当たり判定はJS側に同一の卵SDFを持ちポインタレイをスフィアトレース。**カメラ基底のcross計算はシェーダと一字一句同じ式に**（cross(ww,(0,1,0))=(-wz,0,wx)——符号を間違えると鏡像になり、ライトが反対側に灯る。一敗）。
- ノックの揺れは減衰バネ（k=70,c=6.5）をヨー/ピッチに足す。背景がほぼ無地なのでカメラ揺れ=卵の揺れに見える。
- ピンチは pointerId の Map 管理＋ `isPrimary` で迷子の指を自己修復（タップが効かない型の予防）。
- 検証用: `?lamp=fx,fy`（画面割合でライト固定）・`?kick=0..1`（蹴りの光を固定）・`?yaw=R`・`?warm=N`。

## 物理が演出を書く（構成要素）

- **卵形**: 円弧合成の厳密な卵SDF（IQ の moss egg）を回転体化。楕円近似ではなく本物の卵曲線。回転体はプロファイル2D SDFをそのまま `vec2(length(p.xz), p.y)` で評価すれば厳密。
- **透光**: Beer–Lambert の波長別吸収 `σ=(0.78,1.95,3.55)` で内部発光をレイに沿って実積分（22サンプル+IGNジッタ）。検卵特有の「中心は琥珀・縁は深紅」のグラデーションは物理から出る。
- **血管網**: Gray-Scott 反応拡散（coral growth: F=0.0545, k=0.062）を768×384のequirectテクスチャで実時間成長させ、内膜面に貼る。胚の一点からシードし、一生の間じゅう本当に「育つ」。
- **鼓動**: lub-dub 二拍のガウス波形。bpm は一生の進行で 42→100 に上がり、拍位相はJS側で積分してuniformで渡す（bpm変化時の位相飛びを防ぐ）。
- **ひび**: 3D voronoi の稜線 (F2−F1) を fbm でドメインワープ。嘴打点（NUC）からの角距離＋セルごとのハッシュ閾値で伝播。ひびは透過光の増幅率として掛ける＝内部が明るい所ほど金色に光る。

## 踏んだ罠・学び（再発見コストが高い順）

1. **薄い発光レイヤを体積積分で拾うと放射状の縞が出る**。内膜（血管の層）を26サンプルの積分に混ぜたら、レイごとのエイリアシングが放射状バンディングになった。→ 薄層は「レイが面を横切る点」で面として1回評価する（手前の内膜横切り＝入射点方向のRDサンプル）。縞が原理的に消え、しかも斜め横断の光学厚 `1/cosθ` で縁ほど濃くなる副産物つき（実物の検卵と同じ見え方）。
2. **血管は発光ではなく吸収**。最初発光で描いたらイースターエッグの飾り模様になった。血液は透過光を遮る＝背後の光に暗い深紅のtintを掛けると、一気に「命の影」になる。
3. **Gray-Scottの成長は速い**。RD_RATE=900/s では45秒で全球を覆い尽くした。320〜480/s に落とし「一生の中で育ちきらない」量に配る（六花の「総予算÷成長時間」原則）。
4. **格子のジグザグはドメインワープで崩す**。GS coral は9点ラプラシアンでも45°の規則性が残る。RDテクスチャのサンプリングUVを `fbm(dir*5.7)` で±0.045ワープすると有機的な曲線になる。voronoiのひびも同様（座標を fbm で±1.15ワープ→稲妻状の毛細ひびに）。
5. equirect の RDシード位置と3D側の胚方向は一致させる：シード uv(0.5,0.56) ⇔ 方向 `normalize(vec3(0.98,0.196,0))`。
6. ブルームのアップサンプルは down結果をコピーしてから ONE,ONE 加算（読み書き競合の既知の罠を回避）。ダウンサンプルUVは dst texel 基準。
7. 検証は `?warm=N`（simTime とRDステップを同期して先送り）＋ `?yaw=R`（カメラ固定）。非表示ペインでは rAF が絞られるので実時間検証は不可。

## パラメータの勘所

- 一生: PERIOD=104s。burst のガウス中心 phase=0.925・幅0.028。フェードは 0.962→0.998。
- 吸収σを下げると発光的に、上げると陶器的になる。(0.78,1.95,3.55) が「殻の中の命」の均衡点。
- ひびの線幅は F2−F1 で 0.026。0.05 だとステンドグラスになる。
- 命のゆらぎ: life に 2周波の正弦 ±3.8% を掛けるだけで「ろうそく」になる。
