# 回折 — Kaisetsu（2026-09-05・ccf5 art）

神聖幾何学の線を透過スリットにして、光を**実際に伝播**する。5〜6月の diffraction_plate / kinoform / moire_engraving（回折を模した装飾）の作り直し。

## 物理
- 角スペクトル法：U(x,y,z) = F⁻¹[ F[U₀] · exp(i2πz√(1/λ²−fx²−fy²)) ]。エバネッセント（fx²+fy²>1/λ²）は落とす。平面波の共通位相 2πz/λ を引いて float の精度を保つ。
- GPU の Stockham radix-2 FFT（1024²・横10＋縦10パス・ギャザー形）。順変換は開口が変わった時だけ、逆変換は毎フレーム波長ごと（白色光は 640/532/450 nm の三本を別々に伝播して RGB に）。
- **タルボ効果**：周期格子は z_T で自己像を結ぶ。六方格子（間隔 d）の逆格子は |G|²=4(h²+hk+k²)/(3d²) なので z_T = 3d²/(2λ)（d=0.2mm・532nm で 112.8mm）。半タルボでは半周期ずれた像。実測の一致度（∫I·A/√(∫I²∫A²)・mipmap 縮約）を右上に出す：z=0 で 0.997、z_T で 0.967（非近軸の補正ぶん下がる）、z_T/2 で 0.215（ずれた像）。
- 白色光ではタルボ距離が波長で違うので、よみがえりが色に分かれる（緑が戻る所で赤と青はずれている）。
- 周期でない形（正本の環・種・メタトロン・ヤントラ・五芒星）はよみがえらない。フレネル像が広がるだけ。

## 窓
- FFT は周期境界なので、窓を六方格子の矩形周期 √3d × d の**整数倍**にする（横 12√3d＝4.157mm × 縦 20d＝4.0mm・非正方）。正方 4mm の窓では周期が切れて一致度 0.888 止まりだった。
- 単位：円の半径 d＝0.2mm、線幅 0.06d。周期でない形は端で折り返す（窓の外へ出た光が反対側から入る）。

## 操作・URL

## 罠
- GLSL ES で `half` は予約語（コンパイルエラー）。
- ピンポンの最初の書き先が読み元と同じテクスチャになり、逆変換が壊れて z=0 の一致度が 0.5 になった。読み元と別の器から始める。
- 1024² 三波長の逆変換（60パス）は M シリーズで 60fps。
