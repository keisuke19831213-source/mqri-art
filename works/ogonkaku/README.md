# 黄金角 — Ōgonkaku（2026-09-05・ccf5 art）

137.5° は、誰も決めていない。5月25日の「phyllotaxis-bloom」（黄金角を式で置いたひまわり）の作り直し。

## 力学（Douady & Couder, PRL 68, 1992）
- 周期 T ごとに頂端の縁（半径1）に芽が生まれ、既存の芽からの斥力エネルギー Σ1/d³ が最小の角度に置かれる（1440方位を走査）。すべての芽は現在の成長率 Gcur で外へ流れる（r ← r·exp(Gcur·dt)）。
- 黄金角は式に入っていない。G が小さいほど発散角が 137.507…° に収束し、左右の近接列（螺旋）の本数がフィボナッチ対になる。G が大きいと二列（180°）。
- **フィボナッチ枝は G を連続に下げて辿る**（ヒステリシス）。いきなり小さい G から始めると別の枝（140.5°・18と23など）に落ちる → Gcur は二列（1.2）から目標へ芽ごとに5%ずつ下がる＝植物の生い立ちそのもの。
- 実測：G=0.10 で 137.25°（直近20平均 136.85°）・螺旋 8 と 21。G=1.2 で 180.00°・2 と 4。

## 表示
- 力学は指数（松かさ）だが、表示の半径は √age（面積を保つ＝ひまわりの詰まり方）。斥力は縁の近くだけが効くので、表示写像は力学に影響しない。
- 螺旋の本数＝最新80個について、左右それぞれの最近傍との番号差の最頻値（S で二族を染める：橙と青、両方に属す芽は白）。
- 発散角のスパークライン（点線＝黄金角）。
