# HIVE RESONANCE — 蜂の巣と周波数

---

## 展示用キャプション

**HIVE RESONANCE — 蜂の巣と周波数**
2026年／ジェネラティブアート（リアルタイム映像・音響）
WebGL シェーダー、CPU パーティクルシミュレーション、Web Audio API

ミツバチの巣は、六角形という自然界でもっとも効率的な充填構造でできている。その格子の上に、目に見えない「音」が定在波としてかたちを結ぶ——本作は、18世紀にエルンスト・クラドニが板と砂で示した「見える音」の実験を、蜂の巣という生命の建築のなかへ移し替えた試みである。

ソルフェジオ周波数と、実際の蜂の羽音（230Hz）が画面を駆動し、15,000の砂粒が振動の節線へと静かに集まっていく。音が変われば模様が変わり、模様が変われば巣のざわめきも変わる。鑑賞者は、聴くことと見ることが分かちがたく結ばれた一つの共鳴場に立ち会うことになる。

*音量にご注意ください。実際の周波数が再生されます。*

---

## 制作メモ

### コンセプト
- 「見える音」= クラドニ図形を、蜂の巣（六角格子）という生命の構造と重ねる
- 周波数を装飾ではなく**駆動源**として扱う——音がビジュアルを生成する因果関係を成立させる
- ヒーリング音楽ジェネレーター（[[healing-tones-project]]）と同系統の周波数テーマを、視覚芸術へ展開した一作

### 技術構成
- **WebGL シェーダー**：蜂の巣格子＋クラドニ定在波パターンを GPU で描画
- **パーティクル系**：CPU 上で 15,000 粒子を更新。振動の節線（変位ゼロの線）へ粒子が集積する砂紋シミュレーション
- **Web Audio API**：ソルフェジオ周波数＋230Hz（蜂の羽音）を実音として発振し、その周波数値がシェーダー／粒子挙動の uniform を駆動

### 素材・出典
- Ernst Chladni のクラドニ図形（1787『Entdeckungen über die Theorie des Klanges』）
- ミツバチの営巣構造と羽音の実測周波数帯
- ソルフェジオ周波数群

### 展示・再生
- 単一 HTML（依存なしの自己完結ファイル）：`hive-frequency/index.html`
- ローカルプレビュー：launch.json の `hive-frequency`（port 8960）
- 音声再生を伴うため、ヘッドフォンまたは静かな環境での鑑賞を推奨
