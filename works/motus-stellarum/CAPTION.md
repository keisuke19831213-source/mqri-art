# 星の運行 — MOTVS STELLARVM

2026 年 / リアルタイム生成アート(Canvas 2D・単一 HTML)

太陽を中心に、六つの星がめぐる。

描かれる運行は本物である。J2000 の平均軌道要素からケプラー方程式を解いて水星〜土星の位置を求めており、日付は実際の暦と対応する。ひらいた瞬間に映るのは、今日の空の配置。

視点を地球へ移すと、星はときに立ちどまり、あともどりして輪を描く——古代の人びとを千年悩ませた「逆行」が、軌跡としてそのまま現れる。ふたつの星をむすぶ線を歳月のなかに重ねれば、地球と金星は八年かけて五弁の花を編む。

- よこにドラッグ:時を送る・巻きもどす
- たてにドラッグ:傾きを変える(立体視点)
- ホイール / ピンチ:遠近
- 星にふれる:名前と距離が灯る
- 地動 / 天動 / 結び の三つのながめ方、平面⇄立体、星名の点灯消灯
- Space:停止 / 再開
