# 星の運行 ─ MOTVS STELLARVM

太陽系の惑星の運行を、時を操りながらながめるインタラクティブなデジタルアート。
単一HTMLファイル・依存ゼロ・ビルド不要。

描かれる運行は本物です。J2000 平均軌道要素からケプラー方程式を解いて水星〜土星の
位置を求めており、日付表示は実際の暦に対応します。初期状態は「今日」の星の配置です。

## 三つのながめ方

| | |
|---|---|
| **地動** | 太陽を中心に六つの星がめぐる公転の眺め |
| **天動** | 地球を中心に据えた眺め。黄道十二宮の環のなかに、惑星が立ちどまり後戻りする**逆行**のループが軌跡として現れる |
| **結び** | 二つの惑星を結ぶ線が歳月とともに幾何学模様を編む。地球×金星では8年周期で五弁の花(五芒の華)が現れる。6組から選択可 |

## 操作

- **よこにドラッグ** ─ 時を送る・巻きもどす
- **たてにドラッグ** ─ 傾きを変える(立体視点のとき)
- **ホイール / ピンチ** ─ 遠近
- **星にふれる** ─ 名前と距離が灯る
- **スペースキー** ─ 停止 / 再開
- スライダーで時の速さ(一秒に0.1日〜8年)、ボタンで平面⇄立体・星名の点灯消灯・軌跡の消去

## 立体視点

各惑星の軌道傾斜角(水星 7.0°、金星 3.4°、火星 1.85° ほか)を含む真の3次元座標を
計算し、黄道面を斜めに見おろすオリー(太陽系儀)風の投影で描きます。奥の星は小さく、
手前の星が奥の星を覆うよう奥行き順に描画。傾きは真上からほぼ真横まで連続的に変えられます。

## 設計メモ

- 描画は Canvas 2D の二枚重ね。背面が軌跡の蓄積層、前面が星と惑星。軌跡層は
  モードごとに異なる速度で減衰させる(結びの模様は消えにくく、天動の逆行は程よく尾を引く)
- 軌跡はフレーム間の時間差を惑星の公転周期で割って細分し、時間を速く送っても
  線が折れないようにしている
- ズーム時は軌跡層をオフスクリーンcanvas経由で拡大縮小して保存する。視点の傾きを
  変えたときだけは過去の線が幾何学的にずれるため消去する
- `prefers-reduced-motion` を尊重(停止状態で開始)

## 開発

```bash
python3 -m http.server 8000
```

`index.html` を開くだけでも動きます。外部リソースへの通信は一切ありません。
