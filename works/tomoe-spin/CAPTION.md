# 巴回転 — TOMOE SPIN

2026 年 / リアルタイム生成アート(Canvas 2D・単一 HTML)

円のなかに、勾玉がひとつだけ置いてある。回すと、三つになる。

画面は1秒間に決まった回数しか描き換えられない。だから「1フレームあたり何度回るか」を 360/N に合わせると、勾玉は N か所にしか現れなくなり、目はそれを重ねて N 個の紋として見る。速度を 360 で割り、既約分数にしたときの分母が、そのまま紋の枚数になる。回転の速さが、紋の数を決めている。

巴紋を巴紋たらしめているのは、勾玉そのものではなく、そのまわりの余白である。姉妹作『太極回転』の太極図をいくら 120°/frame で回しても三つ巴にはならない——余白を持たない図形は、重ねたところで灰色に潰れるだけだからだ。だからここでは、円の三割ほどしか占めない勾玉をひとつだけ置いた。勾玉がそこに在る時間は全体の N 分の1しかないので、黒地では光として加算合成で描く。重なった場所は濁る代わりに輝き、紋は黒漆に金を蒔いたように結晶する。

紋は 360/N の速度でしか組み上がらない。ではもっとも結晶から遠い回転は何か——黄金角 137.5077…°、もっとも割り切れない角度。押すと勾玉は二度と同じ場所に戻らず、ひまわりの種の配置で円を満たしていく。

- ドラッグ:掴んで回す — 離すと勢いのまま回り続ける
- 2〜8:その紋が組める速度と形へ / G:黄金角(永遠に結晶しない回転)
- 巻き:尾の巻きこむ角度 / 太さ:頭の大きさ / 残像:溶かし込むフレーム数
- 漂い:速度をわずかにずらし、結晶した紋を歳差回転させる
- A:鑑賞モード(二つ巴から八つ巴まで巡る・一周およそ90秒)
- H:パネル表示切替 / Space:停止
