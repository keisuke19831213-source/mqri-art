# 火線 — Kasen（2026-09-05・ccf5 art）

ヴェシカ・パイシスはレンズである（lens の語源はレンズ豆＝この形）。5月の vesica 連作（vesica lumen field / tension atlas / morphogenesis…）の作り直し。

## 光学
- 二つの円（半径1・中心距離 d）の重なりに光を通す。入射（Snell・Fresnel 透過率）→ 内部（全反射は最大3回）→ 射出。表面反射は R で点ける（既定は消す：凸面で広がり背景を毛羽にする）。
- 波長 400〜700nm を乱数で振り、Cauchy n(λ)=n0+B/λ²（550nm で n0）で分散。色は近似スペクトル。
- 光線は毎フレーム 6144 本を乱して蓄積（EMA）。光線が集まる包絡線＝**火線（caustic）**がひとりでに現れる。式で描いていない。
- 右上：幅（d=1 で √3）・厚さ・近軸焦点距離（厚肉レンズの式 1/f=(n−1)(2/R−(n−1)t/(nR²))）。

## 罠
- 射出直後に同じ弧を「入射」と誤認して再び中へ入り、光が外に出なかった → 射出したら exited にして直進させる。
- 表面反射は凸面で大きく広がり、背景一面を毛羽にする → 重み 0.08。直進光の帯も落とす（火線が主役）。
- 頂点シェーダで各頂点が自分の線分の端点を求める方式（経路を最初から辿り直す）は 6 線分×2 頂点でも軽い。
