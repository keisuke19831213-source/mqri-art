# 五重格子 — Gojū-kōshi（2026-09-05・ccf5 art）

五方向の平行線の束から、ペンローズ・タイルが厳密に生まれる。5月25日の「penrose_drift」（分割規則の近似）の作り直し。

## 数学（de Bruijn 1981）
- 五方向 e_j=(cos 2πj/5, sin 2πj/5) の平行線 x·e_j = k − γ_j（五重格子）。二本の線の交点ひとつがひし形ひとつ：隣り合う方向（|j−l|≡±1）は太（72°）、二つ隣は細（36°）。
- 交点 x に対し K_i(x)=⌈x·e_i+γ_i⌉、ひし形の頂点は Σ K_i e_i（交点上では K_j∈{k,k+1}, K_l∈{m,m+1}）。これが双対で、タイルは隙間なく重なりなく平面を覆う。
- **Σγ が整数なら真のペンローズ**（H で総和½＝一般化ペンローズ：星が増え、太／細の比は同じφのまま局所構造が変わる）。
- γ は垂直空間 e'_j=(cos 4πj/5, sin 4πj/5) の2成分 (a,b) で動かす（Σe'_j=0 なので総和は保たれる）。ドラッグ＝フェイゾン：交点が線を越えるたびタイルが局所反転し、反転した瞬間が明滅する。
- 右上：太・細の個数と比（画面内で 1.618…）。無限では厳密に φ。

## 描き方
- 交点は毎フレーム JS で列挙（半径内 ~7000）、塗り（2三角）と辺（4線分）を VBO で描き、4× マルチサンプル。格子線は解析 SDF で別バッファに描いて合成（明るい彩では減算）。
- 彩3：漆（金×藍）／和紙（朱×水色）／翠。向き5×太細で10の面色。
